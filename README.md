## 我为什么要做这个东西

其实原因很简单，我自己用 DAZ 3D 用得比较多，但是一直觉得它的更新速度和使用体验在 4.24 以后越来越差，到 DAZ6 Iray 已经卡的没法用了。

我还记得曾几何时 DAZ 的 Viewport Iray 交互要更优秀的多，当年可以开着 Iray 也能让鼠标以相当流畅（至少10帧/s）的速度离线流畅渲染的。

这个问题从4.23以后让我难受了很多年，我也不是没跟官方论坛反馈过，写了个全英文的问题反馈到DAZ Forum，发邮件，人家也承认了这是个问题，但我就没看到他们修复。可能人家太忙了吧。

后来我就想，与其一直等官方慢慢研发，不如我自己从头做一个。至少可以先按照自己的需求来。

赞美AI时代。

## 这个项目想做什么

只关注一件事：提升 Iray viewport 的效率。

它是一个比较轻量、比较简单的 DAZ 场景查看和操作工具。把我原来在 DAZ 里面使用的角色、服装、道具和场景加载进来，然后可以在这个工具里直接预览、调整和操作。

简单来说，我希望它能够解决这样一个流程：

> 打开一个 DAZ 场景，然后快速看到它、调整它、摆一下姿势，再从不同角度预览它。

整个过程不需要太复杂，也不需要为了一个简单的预览操作，启动一整套很重的软件环境。

目前项目已经有了一个基本可用的运行框架，主要功能大概包括下面这些。

### 加载 DAZ 场景和资源

现在可以读取常用的 DUF、DSF 资源，加载角色、道具、服装、头发、灯光等内容，也可以加载一些完整的场景。

项目里有内容库和内容浏览器，可以配置自己的资源目录，然后从里面查找和使用角色、姿势、形态、材质等资源。

“视图 → 材质”打开独立停靠面板，左侧按角色、自身、服装、头发及 GeoGraft 展开子材质，右侧可编辑颜色、贴图、高光、透明、SSS、清漆、自发光、毛发、置换和 UV 等参数。支持表面多选、搜索、还原，以及将通用 Shader 预设应用到所选表面；修改随 Ctrl+S 保存到 `.dufex`。兼容范围见 [材质面板说明](Docs/material_editor_cn.md)。

“近期使用”的图标右键可选择“从近期使用中移除”，不会删除原始文件。

### 在独立视口里预览

项目使用独立的 Cycles 运行时来做场景预览，不需要额外启动 Blender、DAZ Studio 或 Iray。

渲染时按需上传可见对象及其使用的材质，释放隐藏头发等资源占用，并缩短静止采样的显示更新批次。`test9.duf` 头部特写的原因分析、实测数据与后续优化方向见 [渲染性能调查](Docs/render_performance_analysis_cn.md)。

在视口里可以查看当前场景，也可以旋转、平移、缩放相机，聚焦到某个对象。现在也支持鼠标操作和 WASDQE 这类键盘移动方式，方便在场景里观察。

除此之外，还可以调整一些环境、色调和渲染相关的选项，让预览效果更接近自己想要的样子。

“项目 → 项目设置”按功能分为“资源与保存”和“渲染”选项卡，内容库路径、保存文件及各组渲染设置均可折叠。“渲染”页包含独立的 50%～100% 渲染倍率、双线性／双三次升采样与 50%～200% 界面缩放，以及 512／1024／2048／4096／无限制纹理最大分辨率、皮肤 SSS、凹凸与法线和透明层数上限。“应用”立即更新当前窗口，“保存”同时保存设置供下次启动恢复。默认保持原画质；纹理或材质质量改变时释放旧 GPU 会话并重新加载资源，保留当前编辑和相机。详见 [项目与渲染设置](Docs/project_render_settings_cn.md)。黄色选择区域始终覆盖在服装等遮挡物上方，重叠表面只叠加一次黄色。材质支持发光色与亮度贴图、色温、亮度单位和单双面发光。

我按自己的习惯顺便还做了个单手（纯鼠标）自由移动相机的交互模式，但需要用一个支持侧键的鼠标。

### 调整角色和姿势

场景编辑支持 `Ctrl+Z` 撤销、`Ctrl+Y`／`Ctrl+Shift+Z` 重做，包括新建和替换场景；连续拖动计为一次操作，相机导航不进入历史。“项目设置 → 资源与保存”可调整历史上限，默认 50 条。编辑后自动写入恢复点，异常退出后再次启动会询问是否恢复最后场景与暂存参数。覆盖范围与扩展接入方式见 [撤销、重做与异常恢复](Docs/undo_redo_cn.md)。

目前已经接入了 Genesis 8、Genesis 8.1 等角色的基础骨骼和蒙皮处理，也可以加载和应用 Pose DUF 姿势文件，也对一些 GeoGraft 做了支持。

在场景树或者骨骼层级里选择角色部位之后，可以对它进行位置、旋转和缩放调整。项目现在也在逐步完善 FK 和 IK，让摆姿势的时候不需要完全依赖传统的骨骼层级操作。

现在也可以使用视口 Gizmo 直接平移、旋转和缩放节点，平移支持三轴及三个平面，平移与旋转分别记忆 Local／World；未命中手柄时仍可拖动 IK。Local／World 右侧的功能模块提供地面对齐比例与 `Ctrl+D` 对齐到地面，适用于角色、普通物体及 DAZ Instance。菜单、3D 工具和角色功能默认同行，可独立移动、换行或浮动，并保存布局。具体操作见 [Gizmo 与顶部栏说明](Docs/gizmo_controls_cn.md)。

### 调整 Morph 和角色参数

“对齐到地面”旁的砝码可以为角色添加独立的生长与体重参数，或为普通物体添加密度与重量参数。年龄支持小数和步进，后台测量标准站姿身高、体重及部位重量；生长组与 Morph 列表均可折叠。使用 `Ctrl+S` 将场景修改保存到同名 `.dufex`，下次打开 DUF 自动恢复，扩展文件中的改动优先。详见 [生长与保存说明](Docs/growth_weight_dufex_cn.md)。

若 DUF 含可匹配的原生生长或密度通道，对应扩展组会自动挂载并按项继承原值；未匹配项保留默认值。“步长”控件的滚轮与上下按钮增量为 0.25。本轮兼容性修复及验证见 [体验反馈记录](Docs/experience_feedback_execution_cn.md)。

“编辑 → 测量单位…”设置全局倍率，身高按倍率、重量按倍率立方显示，并自动选取 cm／m／km 或 g／kg／t。年龄滚轮与上下箭头遵循“步长”。未指定文件时默认打开空场景，详见 [面板与测量单位](Docs/growth_weight_ui_cn.md)。

项目可以读取角色和资产中的 Morph 参数，并在参数面板里进行搜索、分类和调整。

参数既可以通过滑块调，也可以直接输入数值。部分 Formula、ERC 和 JCM 关系也已经接入，所以一些参数在改变姿势或形态之后，可以跟着一起更新。

### 角色身材系统/成长系统/体重测量（残缺版）

测量角色的身高/体重/控制体格。年龄只是控制生长曲线用的，只是模拟了幼年到成年，无法控制中老年的体型变化。

### 服装和附加物跟随

现在已经支持角色和服装、头发、GeoGraft 等附加对象之间的基本关联，也在处理 Fit To、骨骼跟随和部分表面跟随逻辑。

也就是说，角色穿上服装之后，服装可以跟着角色一起移动和摆姿势。这个部分还在继续完善，因为真实的 DAZ 服装和附加物情况比较复杂，很多资源都有自己的特殊处理方式。

### 基本场景编辑

目前可以在场景里新增、删除和替换对象，也可以创建空场景、重新加载场景和管理场景树。

项目还支持保存项目配置、渲染选项和一些常用收藏内容。
