# 顶部空白区域拖动修复

2026-09-26。

顶部菜单及工具模块的空白区域现在可以拖动整个窗口，包括工具栏尾部、分隔处和换行后的空白。双击空白可最大化／还原，最大化状态下拖动空白可恢复普通窗口。

菜单、工具按钮、比例输入框、溢出按钮、应用图标和窗口按钮继续响应各自操作；模块左侧把手继续用于重排、换行和浮动。浮动模块不会启动主窗口拖动。

旧的 `caption_at` 只识别专用拖动区、模块容器本身和没有子控件的位置；大片空白实际属于 `QToolBar`，因此返回了普通客户区。现在按工具栏实际动作区域与样式给出的把手区域识别空白，原生命中测试和 Qt 鼠标事件共用这套判断。Qt 控件先接收鼠标消息时，通过 [QWindow::startSystemMove](https://doc.qt.io/qt-6/qwindow.html#startSystemMove) 启动系统移动，保留窗口管理器的原生拖动行为。
