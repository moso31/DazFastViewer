# 快速物理

勾选“启用快速物理”只准备模拟；点击“模拟 N 轮”后，物理世界从当前位置和速度逐步推进，到达 N 轮后停止，不等待整段迭代结束才显示。每个角色有独立的世界和后台线程；普通物体共用一个刚体世界。显示可以晚于解算，物理工作不占用视口交互线程。

## 使用方法

1. 选择普通物体、服装或发型的根节点。独立的“物理”组位于“部位重量详情”下方、“对象属性与 Morph”上方。
2. 打开“启用快速物理”。默认关闭，角色本体和骨骼不显示此组。
3. 在“组合／约束”中勾选需要参与的子材质；“全选”可统一勾选或取消，部分选中时显示半选状态。未勾选的部分继续原有跟随。“勾选的子材质作为整体解算”默认开启。
4. 设置轮数（默认 20 轮）并点击“模拟”。每轮推进 `1/60` 秒，执行完毕后保留状态；再次点击从当前状态继续 N 轮。调整轮数只影响下次运行。
5. 同一行的“重置”恢复初始跟随形状并停止。质量、阻尼、固定范围、组合等物理参数改变后，同样恢复初始状态，等待再次点击模拟。
6. 关闭“启用快速物理”恢复原有跟随；再次启用仍需点击模拟。项目设置保留全局暂停，可冻结尚未完成的轮数。

物理组展开时始终显示全部参数。物理、重量详情、对象属性与 Morph 共用属性页的一个竖向滚动条，各组可分别收起，收起后从顶部排列。只有左键选中的物理参数响应滚轮调值，其余位置的滚轮滚动页面。

参与的子材质以流式复选框铺满可用宽度；悬停时使用与射线选取相同的黄色遮罩高亮，避免深度竞争。场景树外的“仅显示物理模型”将已启用物理的根节点列在同一级；取消勾选恢复原有层次，不改变对象显隐。

“模拟方式”可自动识别或手动指定。鞋履自动识别为刚性穿戴物，保持角色挂接；普通物体使用自由刚体。衣物使用布料代理，贴片发型和 Strand Based Hair 使用引导发束。

每件服装、每个发型根节点独立控制。Mega Updo Base、Bangs、Bun 若在资产中为多个根节点，分别启用；本版的子材质组合不会跨这些根节点强行焊接。Shell、GeoGraft 依赖表面及 DAZ Instance 引用节点不提供独立开关。

## 组合与参数

| 控制 | 效果 |
|---|---|
| 参与的子材质 | 按几何表面划定范围，不读取材质的着色属性。与未选表面共享的边界顶点保持跟随 |
| 作为整体解算 | 刚体保持选中部分的整体形状；布料和发束在分离部件间建立距离约束，仍允许柔性变形 |
| 关闭整体组合 | 普通刚体按子材质分别模拟；布料和头发保留各自拓扑连通片，不增加跨部件连接 |
| 质量、摩擦、弹性 | 质量与接触控制；弹性用于刚体 |
| 阻尼 | 减少晃动 |
| 形状保持 | 布料和发束约束强度 |
| 根部固定范围 | 以导入形状识别衣物上部、发束根部；旋转角色不会重新选择另一端 |
| 最大活动距离 | 限制相对当前跟随形状的位移；复杂盘发可缩小范围 |
| 碰撞厚度 | 软体粒子的接触距离，单位 mm；实际软体厚度上限为 10 mm，避免过大的碰撞壳挤开附件 |

改变某件对象的物理系数、模拟方式、表面选择或整体组合，只将这件对象恢复初始状态；同角色其他穿戴物保留已有状态，其他角色继续运行。全局重力、地面、质量档位改变时，所有相关对象恢复初始状态并停止。全局暂停、显示刷新率和轮数调整不会重置模拟。姿势／几何跟随变化仍尽量转移已有位移和速度。

## 时间与交互

每个世界一次只推进 `1/60` 秒，慢步之后不追赶补算。三档质量的每件软体代理预算分别为 384、768、1536 点，对应 2、4、6 次约束迭代。每件对象独立消耗本次运行的轮数；预算用完后不再继续推进。

项目设置 → 物理 → “物理帧刷新率（次/秒）”默认 `4`，支持任意有限正数及科学计数法。这是显示请求的目标频率，不改变固定解算步长。后台按需求展开变化网格；提交频率同时受设置间隔和新渲染帧限制，最快不会超过渲染帧率。没有几何变化的物理帧只更新状态，不重置 OptiX。完整渲染或网格准备较慢时合并显示请求，实际刷新率可能低于设置值。拾取、高亮和边界准备只更新变化对象，不再重建整个场景。碰撞构建、物理小步、选取数据、OpenGL 缓冲准备、Cycles 几何提交均在后台完成；相机静止时保留上一张完整渲染图，等待新图替换；操作相机和编辑时立即使用基础网格预览，继续处理点选和拖动。

虚拟地面默认为 DAZ `Y=0`，可在项目设置调整高度或关闭，也可调节重力。角色身体仅作为碰撞依赖，不能启用身体动力学。其他未模拟衣物／发型不会被误当作刚性障碍物。

对象参数及子材质选择随 `.dufex` 保存，参与撤销和恢复；全局设置随项目保存。源 DUF、DSF 和渲染材质不变。动态位置、速度不会写入场景文件：重新打开／切换文档从当前场景的跟随形状开始。运行／重置命令和动态状态不持久化，重新打开后仍需手动点击模拟。

## 当前边界

- 固定区域仍为自动估计，尚无手绘权重。复杂盘发、特殊裁片和倒置导入资产可能需要调整参数。
- 代理点从实际发片表面选取；碰撞修正受单步位移限制，减少深穿透时的瞬间弹飞。这不能保证消除任意商业资产的穿模。
- 尚无通用布料自碰撞、两个软体间的完整互碰。不同角色世界之间不做穿戴物互碰，多层裙摆仍可能穿插。
- 普通刚体用凸包，构建失败时用包围盒，凹形空洞不提供精确碰撞。角色上的刚性配件保持随动，不会自由掉落。
- 子材质范围不能跨根节点组合；多个实例共享同一网格时，不支持分别改变其顶点。

引擎为本机静态编译的 Jolt Physics v5.6.0 CPU 后端。构建脚本获取并校验固定提交，无需额外安装物理运行环境。许可证位于 `out/vs2022/Release/licenses/jolt/`。
