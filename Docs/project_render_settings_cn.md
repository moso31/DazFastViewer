# 项目与渲染设置

入口为 **项目 → 项目设置…**。原来的一级“设置”菜单已迁入此处。

“资源与保存”页保留资源库路径的添加、删除、排序，以及当前项目保存文件的位置。两组内容使用与 Morph 类似的折叠模块。“渲染”页分为界面与视口、纹理精度、材质质量三组，后续可以继续增加选项卡。

场景的资源搜索路径分为内容库与 DAZ Studio 内置 Iray 资源。`/Runtime/Textures/...` 等引用按项目中配置的内容库顺序解析；`/resources/DTHDR-RuinsB-500.hdr` 则还会查找本机 DAZ Studio 的 `shaders/iray/resources`。程序读取 Windows 注册表中的 DAZ 安装位置，并保留 Program Files 默认安装位置作为回退，支持安装在其他磁盘或自定义目录，不再写死 `C:/Program Files/DAZ 3D`。自动发现的 Iray 路径不会加入内容浏览器的资源库列表，也不会修改项目文件或系统设置。

例如 DAZ 安装在 `C:/Daz 3D/Applications/64-bit/DAZ 3D/DAZStudio4` 时，通常无需额外设置。未注册的便携安装可将环境变量 `DFV_DAZ_STUDIO_PATH` 指向 DAZStudio4 安装目录；也可以在“资源库路径”中手动添加 `C:/Daz 3D/Applications/64-bit/DAZ 3D/DAZStudio4/shaders/iray`，注意添加的是 **iray 目录，而不是 resources 目录**。显式配置的资源库优先于自动发现的位置。诊断文件 `asset-report.json` 的 `iray_resource_roots` 记录本次使用的自动搜索目录，`render_options.environment_file` 记录最终解析的 HDRI 文件。

DUF/DSF 中保存的 Windows 绝对资源路径先检查原文件；若原文件不存在，且只改变了盘符、库内目录结构不变，则按当前配置的库重新定位。例如配置 `G:/G1` 后，`H:/G1/Runtime/Textures/...` 可定位到对应的 `G:/G1/Runtime/Textures/...`。不会按文件名在磁盘中搜索替代贴图；资源库改名或目录层级改变时，应更新源引用。此重定位针对 DAZ 资源引用，不改写源场景。

| 设置 | 默认值 | 调整后的影响 |
|---|---|---|
| 界面缩放 | 100%，继承原偏好 | 文字、图标和控件大小，范围 50%～200% |
| 视口渲染倍率 | 100%，继承原偏好 | 范围 50%～100%；50% 约计算四分之一像素，细节减少 |
| 升采样方式 | 双三次，继承原偏好 | 双线性较柔和，双三次较清晰 |
| 视口锐化强度 | 0.00（关闭） | 位于“界面与视口”，滑块范围 0.00～20.00，右侧显示小数；增强边缘与局部对比度，过高可能放大噪点 |
| 纹理最大分辨率 | 无限制 | 512、1024、2048、4096、无限制；降低后减少显存与纹理细节 |
| 皮肤次表面散射（SSS） | 开启 | 关闭可减少部分角色的计算量，但皮肤透光与柔和感改变 |
| 凹凸与法线 | 开启 | 关闭减少材质计算与表面细节，不关闭几何置换 |
| 透明层数上限 | 32 | 可设 1～32；较低值可能让深层发片、睫毛或透明物体变暗 |

“应用”立即更新当前窗口的资源库、界面和画质，保持设置窗口打开，不写入配置。“保存”应用并保存当前全部设置，然后关闭窗口；资源库路径写入原项目 JSON，界面和画质写入应用偏好。“取消”丢弃尚未应用的修改，已经应用的设置继续生效，但不会因此保存。

沿用旧菜单的界面缩放、渲染倍率和升采样键，既有设置会继承。重新启动恢复所有已保存的设置，包括选项卡位置和模块折叠状态。

锐化在 GPU 视口显示阶段执行，适用于 100% 分辨率及双线性／双三次升采样。邻域范围限制用于抑制边缘光晕；它不会恢复低分辨率已经丢失的细节。“应用”立即更新当前显示，不重建渲染会话、不清空采样，也不修改模型、材质或导出的渲染数据。“保存”将强度写入应用偏好 `viewport/sharpenStrength`；默认 0.00 保持原显示结果。旧百分数配置自动除以 100 继承：原 100% 对应 1.00。滑块范围 0.00～20.00，右侧保留两位小数；方向键微调 0.01，翻页键调整 0.10。

纹理与材质质量变化会在渲染线程中先停止旧会话、释放旧图像管理器和 GPU 设备资源，再按新设置创建会话。旧大纹理不会与新纹理长期叠加。保留文档、未保存的编辑快照与相机，不重新读取 DUF，也不改写原始材质和贴图。相同画质重复应用或保存不会重建；只改变渲染倍率或升采样方式继续使用原有视口更新路径。

停靠面板标题现在随界面缩放同步调整。根因是 [Qt 6.10.3 的 QDockWidget 标题绘制](https://github.com/qt/qtbase/blob/v6.10.3/src/widgets/widgets/qdockwidget.cpp#L1485)会使用创建时缓存的字体；现在绘制标题及计算文字裁切时统一使用当前控件字体。停靠标签与面板内容继续同步缩放。

这些选项提供画质与性能取舍，不保证任一角色达到固定刷新率；也没有开启降噪或默认降低画质。

## 验证

- `ProjectSettingsTest` 验证两页结构、折叠模块、旧偏好继承、应用／保存／取消、应用不写磁盘、先应用后保存资源路径、所有纹理档位重开恢复、材质质量对原场景的保护。
- `UiScaleTest` 测量实际绘制的停靠标题字高：修复前 100% 和 200% 均为 9 像素，修复后为 9 和 18 像素；恢复 100%、缩放期间新建停靠窗口、停靠标签和内容字号均通过检查。
- `RendererQualityTest` 使用副屏真实 Qt / Cycles / OptiX 渲染线程和一张 4096 RGBA 纹理，依次切换无限制 → 512 → 1024 → 2048 → 4096 → 无限制。设备分配从 642,718,916 字节降至 576,658,628 字节，释放 **63 MiB**；恢复无限制后精确回到初始分配量。过程中编辑版本、对象变换和相机保持一致，相同参数重复提交不重建。
- 额外检查 SSS、凹凸／法线和透明层数设置交给渲染线程；实际透明层数可在退出报告中核对。
- 锐化验证覆盖设置所在模块、旧偏好默认关闭、应用／保存／取消及 0%／100% 持久保存。真实 OpenGL 像素检查覆盖原分辨率和两种升采样、强度变化、平坦区域与边界、关闭后逐像素恢复；真实渲染线程检查确认调整锐化不改变会话或采样轮次，也不降低已有采样数。2026-09-28 的构建、界面截图和 GPU 证据位于 `artifacts/viewport-sharpen-20260928/`，28 项常规回归全部通过。
- 验证只启动本次的小型测试程序，未关闭其他应用，没有用小场景内存数据宣称 test9 整体性能达标。

原始证据位于 `artifacts/project-render-settings/`；该目录为本地验证产物，不写入源场景。
