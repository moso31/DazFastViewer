# 材质面板

通过“视图 → 材质”打开独立停靠面板。可以拖动标题改变停靠位置、与其他面板组成标签页，或浮动为窗口；布局随主窗口保存。

左侧默认显示当前角色自身及关联服装、头发、GeoGraft，每个对象下列出实际材质槽。选择骨骼仍查看其角色材质；也可切换“全部场景对象”。隐藏对象的材质同样可以编辑。普通物件和 DAZ Instance 可在全部对象范围内独立选择。

单击子材质在右侧编辑，Ctrl / Shift 可多选。选择对象或角色组会编辑其下全部表面；不同值显示“多值”，输入后统一修改该项。颜色单个分量的修改保留各表面的其他分量。搜索支持中文及英文参数名，“已修改”只显示有覆盖的参数；修改项标题加粗。每行的 ↺ 和“还原所选材质”分别还原单项和整个表面。

参数名、输入控件和还原按钮排列在同一行，↺ 始终位于行尾。必须先用左键点选属性，才能用滚轮修改该行；在其他属性上滚动只滚动列表。贴图文件名右侧显示异步加载的缩略图；多选不同贴图时不冒用某一张图代表所有表面。

悬浮左侧对象或子材质时，视口以黄色标出对应表面。点击后立即隐藏；留在同一条目内移动不会重新亮起，移至其他条目或重新进入后恢复。高亮使用独立遮罩合成，不改变材质、采样或场景选择，也不会因重叠表面产生深度竞争。

## 参数与贴图

提供基础色、金属度、裁切透明、薄壁、高光与各向异性、折射、薄壁透光、SSS、Diffuse Overlay、Top Coat、双高光、法线、凹凸、置换、自发光、毛发和 UV 参数。参数按当前 Cycles 材质模型分组，可折叠。

- 数值支持滑块和直接输入，滑块支持 Shift 精细拖动。距离在界面标明 mm / cm，内部统一转换为米。
- 颜色按钮打开 sRGB 选色器，RGB 数值同样使用 sRGB，可直接输入 0–10 的 HDR 分量；写入渲染器前转换为线性值。颜色按钮仍显示普通屏幕可表示的颜色。SSS 半径为三个独立距离值。
- 点击贴图按钮可选择已有场景贴图、浏览新的图像或移除贴图。颜色贴图按 sRGB，权重、粗糙度、法线、高度按线性数据处理；选择已有 LIE 贴图保留其图层。
- 参数遵循所属材质层的启用条件：例如清漆权重为零时，清漆粗糙度不产生可见效果；SSS 应用于非薄壁表面，毛发模型使用专用毛发参数。全局画质关闭 SSS 或凹凸／法线时，对应材质参数仍保留。

“应用材质 / Shader 预设…”将 DUF 预设应用于左侧所选表面。普通材质按表面名称匹配；通用 `preset_shader` 可应用到任意选中表面。内容浏览器打开材质预设时，匹配当前对象的材质槽，因此全身／整物体预设可以一次替换多个表面，眼睛、指甲或脸部预设只影响其声明的表面。

预设按实际写入的通道合并。只换颜色不会清掉原贴图，只换贴图不会改掉颜色；明确的空贴图会移除原图。仅清除被预设覆盖的对应手动参数，保留其他手动修改和未匹配表面。复合的高光／散射参数会基于合并后的通道重新转换。此规则也用于 DUFEX 重放，局部预设不会用默认值覆盖整套皮肤。

支持实际值保存在 `scene.animations` 零帧中的材质，包括只有动画通道的局部预设；材质定义中的默认值不会误当作当前值。层级材质预设按对象身份和表面名称匹配当前角色及关联对象，不会把材质引用当成新模型追加。预设指定的 UV Set 会更新相应表面的三角面、多边形和发丝坐标；共享网格在修改前隔离，顶点数不匹配时拒绝应用。DAZ Instance 的独立 UV 仍与原型共享，需要在原型上更换不同的 UV Set。

场景树中的选中模型文字加粗。模型右键“在内容库中定位”根据实际资产引用查找对应的可加载 DUF；场景中的对象不会误定位到场景容器或底层 DSF。近期使用列表的同名命令定位记录中的文件。两者均展开祖先目录，在异步读取结束后纵向、横向滚动到目标文件夹，并在右侧选中和滚动到资源。定位及切换内容库／近期使用均保留搜索文本，搜索只在内容库生效；定位时暂时显示目标目录，按 Enter 或修改文本恢复搜索。

## 保存与隔离

Ctrl+S 将材质修改及预设应用写入同名 `.dufex`，重新打开场景自动恢复，原 DUF／DSF 和贴图不被覆盖。旧版无材质字段的 DUFEX 继续兼容。

覆盖按实例身份和表面名称保存；即使两个角色或两个表面最初共享材质，编辑仍互相独立。追加、删除和资源索引整理不改变覆盖的归属；追加另一份带 DUFEX 的场景时会重映射身份。相机、Morph、姿势和细分更新保留材质修改。

## 兼容边界

右侧底部“源通道与兼容信息（只读）”保留导入时的原值、类型和贴图引用。上方编辑的是转换后的 Cycles 参数，不是完整的 Iray Shader 编辑器。多选时源信息显示第一个表面。

Iray Uber、传统 DAZ Default／3Delight 和已识别毛发材质沿用项目的转换。SSS 使用转换后的散射颜色与半径；Iray 体积散射、能量分配和绝对光度不保证等价。Diffuse Overlay 使用漫反射层混合近似。新增双高光粗糙度贴图、发梢颜色贴图和毛发粗糙度贴图映射。

尚未映射的通道明确显示“未映射”，不会提供虚假的可编辑开关。例如自定义 MDL／Shader Mixer 网络、Iray 专有体积／薄膜／部分颜色效果、部分独立清漆法线与高光纹理通道、IES 配光及依赖产品脚本的处理，没有承诺全量支持。关闭的专有参数也会列为未映射；通道数量不能直接视为可见效果缺失的比例。

分层贴图沿用当前渲染器支持的合成方式；独立图像修饰中的非默认变换／取值调整、图层蒙版及专有叠加运算仍可能无法完全还原，导入报告会记录对应警告。此功能不等同于 DAZ 的完整 LIE 编辑器或专有 Shader 网络执行器。

独立 `preset_layered_image` 通常需要把当前底图插入预设的图层栈，不能当成普通替换贴图。当前会明确拒绝直接叠加这类预设，防止用透明纹身／妆容图覆盖整张皮肤；可以先在 DAZ 中合成并保存完整材质。普通材质中的 Diffuse Overlay 妆容和已经保存完整图层的材质继续支持。

`tools/audit_material_library.py` 只读清点内容库，识别 gzip DUF／DSF，默认每目录读取一个文档，并明确记录跳过项、过大文件和读取失败。`--per-folder 0` 可读取全部候选文档；data 中非材质／Shader 的 DSF 仍单独统计为跳过。不会执行资源脚本。

```powershell
python tools/audit_material_library.py H:/g1 H:/g3 --output artifacts/materials/library-audit.json
```

本次检查证据保存于 `artifacts/materials/`。工程测试 `materials` 覆盖对象隔离、资源增量更新、贴图、DUFEX 磁盘往返与 Shader 预设重放、无效数据原子拒绝、旧文件兼容和真实 Qt 控件操作。`RendererMaterialsTest` 是使用实际 Renderer／OptiX 的独立副屏测试。

### 初版材质库抽样

枚举两库共 437,762 份 DUF／DSF，按目录抽样读取一个候选文档；262,155 份非材质 data DSF 和 164,589 个同目录其他候选文件跳过。抽样覆盖 7,706 个含材质的文档、133,846 条材质记录，发现 1,137 种原始通道 ID。此统计用于识别类型，不能视为所有资产均已完成渲染验收。

主要类型为 Iray Uber（112,916 条类型标记）、DAZ Brick（5,763）、传统 DAZ Shader（2,853），另有 Octane 专有数据和 strand hair。当前只转换已识别的通道，不执行这些附加网络。

初次清点跳过 23 个解压后超过 32 MiB 的文件，6 个含字符串通道描述的文档没有完整计入。工具已修正为跳过这类非参数描述，原始清点报告保留当时记录。真实预设导入结果另存 `library-samples.json`，包含未映射通道数和资源警告；资源依赖缺失时保留预设内通道，不会伪称完整还原。

初版 26 项工程检查与 12 个真实预设导入检查通过；初版证据保留于 `artifacts/materials/validation.json`。

### 反馈修订的全库清点

`tools/audit_material_presets.py` 逐个检查 H:/g1、H:/g3 共 **175,589 个 DUF** 的头部，并解析材质、层级材质、Shader 和未知类型候选文件，解压上限 32 MiB。统计到 68,551 个普通材质、10,896 个层级材质和 2,777 个 Shader 类型声明；78,189 个文档包含材质定义，共 675,990 条记录、949 种定义通道。材质库定义与场景绑定会分别计数，因此记录数不是独立材质球数量。

这些文档中 78,184 个含动画通道，63,370 个含 `image_library`，证实实际参数和贴图不能只从 `material_library` 默认值读取。主要依赖是本文件材质定义、Runtime 贴图、UV Set，以及 OmniHair、PBRSkin、Blended Dual Lobe Hair、AoA Subsurface 等 Shader 资产；自定义 Shader 仍只转换已有映射。

报告保留 547 个读取／解析失败项和 9 个超过解压上限的文件。另识别到 1,972 个 `preset_layered_image` 类型头部，其图层语义不纳入本轮完整解析与支持承诺。原始统计见 `artifacts/materials/presets-full-audit.json`，全量清点不等同于逐个渲染验收。

修订后的真实样本检查覆盖 25 个普通／层级／Shader、妆容、眼睛、指甲、毛发和道具预设，验证导入及材质替换，未发现贴图或 Shader 依赖缺失警告。合成网格样本不验证产品的真实 UV 拓扑；UV 接缝、共享网格隔离及层级同名表面使用独立夹具检查。

修订的实际 Renderer／OptiX 检查共 11 个阶段，包含材质悬浮与清除，全程保持一个会话。部署程序为 `out/DazFastViewer.exe`，本轮测试和源码／二进制核对见 `artifacts/materials/feedback-validation.json`。
