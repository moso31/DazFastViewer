# 原生生长、重量与 DUFEX

## 使用方式

- 在“对齐到地面”旁增加砝码按钮。选中角色后点击，添加“生长与体重”组；选中普通网格则添加“密度与重量”组。重复点击打开已有组，不重置参数。未启用的对象不显示此组。
- 新组位于“重置选中对象”和 Morph 搜索框之间，可折叠；下方的对象属性／Morph 列表也可独立折叠。
- 第一行“年龄／步长”，年龄滚轮和上下箭头均按当前步长变化；第二行“体格／每年增长／−／＋”，右侧按钮只调整缩放。年龄范围 1～20，默认 3；步长默认 1，体格默认 0.5，每年增长默认 5。注册本身不改变现有外形。
- 加大字号显示身高、体重，主要标签加粗；详情默认收回，按手臂、腿、手指、脚排列，不使用表格。对称肢体仅计算一侧，文字去掉左右，详情显示单侧重量；全身体重仍按完整模型计算。普通物体提供密度（kg/m³，默认 1000）和重量；不再显示体积、标定段和网格提示行。
- “编辑 → 测量单位…”调整全局倍率，默认 1×，自动记住。身高按倍率、体重和部位重量按倍率立方显示，不改动几何。身高低于 10 m 用 cm、低于 10 km 用 m，其余用 km；重量低于 1 kg 用 g、低于 1 t 用 kg，其余用 t，最多两位小数。倍率用十进制运算，极端大小使用科学计数法。
- “文件 → 保存场景修改”（Ctrl+S）保存 DUFEX v2。打开 `test.dufex` 恢复修改后的场景；打开 `test.duf` 读取原场景，两者独立。内容库、搜索及近期记录同时显示同名的两个文件。
- 保存时自动截取当前渲染视口中间的正方形，缩为 256×256，写入 `test.dufex.png`；不包含选取轮廓、Gizmo 或界面。等待当前编辑对应的画面后截取，保存观察角度并在重开时恢复。缩略图立即在内容浏览器刷新。
- 参数星标的收藏与取消收藏也写入 `.dufex`，不同对象、骨骼、灯光分别记录。旧版仅保存在本机的记录在首次加载时接入；之后以扩展文件为准。
- “重置选中对象”保留已添加的扩展组，将扩展参数恢复默认值，并按原有规则重置形态与变换；不会读取旧 DUF 生长字段。

## 实现思路

1. **规则原生化。** 将 `H:/g1/scripts/lib/growage_common.dsa` 的 19 项年龄形变表和体格强度五档插值移入 C++；年龄与强度均连续插值，批量提交 Morph，复用现有 ERC、服装跟随和后台形变。缺少的资产参数明确列出，不伪造效果。`Simple_Dialog` 只作为注册默认值参考，其旧表不参与计算。
2. **独立扩展状态。** 参数存入对象状态快照，按稳定对象 ID 隔离，不伪装成 Morph。旧 DUF 的 Age、Age Step、Age Sensitivity、Body Strength、Density 自定义通道不继承、不显示；原生 Height、Weight 等实际形变资产继续使用。首次启用保留当前外形，主动修改年龄／体格时才使用生长表。
3. **可逆缩放。** 按实际年龄差和敏感度调整等比缩放，保留脚本的 Y 位移比例规则，年龄边界不额外缩放。已确认去掉旧脚本的约 1% 额外补偿，直接校准实际缩放，避免反复增减累积偏差。
4. **后台测量。** 在独立快照中清零姿势、重应用当前年龄形变、使用基础网格测量，保留实际缩放。原场景、选中对象和姿势不变。移植面体积积分、面组边界封口与 `shape_volume_height_v2` 三段标定；局部重量共用全身有效系数。缓存拓扑与结果，合并连续修改，过时结果不能覆盖新对象或新输入。密度变化只重算乘法。普通物体按闭合网格体积乘密度估算；缺失面组和非闭合网格显示状态。
5. **DUFEX v2。** 将完整 DUF 底稿、结构操作和最终编辑值一起保存为 gzip 压缩 JSON。底稿在导入时冻结，不在保存时重新读取可能已变化的源文件；包括参与加载的其他 DUF、追加场景和材质预设。每次导入有独立来源域，同一路径的多个版本可以共存。底稿保留完整原文和 SHA-256 校验，重开不依赖原 DUF／预设文件仍存在。原 DUF 只读，输出使用临时文件和原子替换。

## v2 保存范围与边界

恢复时通过冻结的底稿和结构操作重建场景，再按稳定 ID 应用作者输入。不会把已求值 Morph、ERC、蒙皮、服装跟随再次烘焙为输入，避免重开后重复变形。重建后的节点、实例原型、Shell、GeoGraft 及各类绑定关系必须与保存的关系清单一致。

| 类型 | 保存内容 |
| --- | --- |
| 场景与节点 | 原始节点、空组、父子嵌套、标签、枢轴、轴向、旋转顺序、缩放继承和显隐；追加、删除、对象及组的本地变换 |
| 骨架与姿势 | 原始蒙皮和绑定定义；各角色独立的 FK／IK／PowerPose 输入、关节中心／末端／轴向偏移、位置及角度固定 |
| Morph 与控制器 | 场景内嵌差值、公式和通道定义；当前编辑值、超限设置，按原规则重算别名、ERC／JCM 与自动跟随 |
| 穿戴及附件 | Parent、Fit To、绑定静止姿势、更换宿主、解除挂接、骨骼附件、Rigid Follow、平滑和碰撞目标 |
| GeoGraft | 宿主和嵌套关系、接缝顶点对、宿主遮盖面、面拓扑、部件 UV／材质及联合细分；无接缝顶点对的纯遮罩也保留 |
| Geometry Shell | 宿主／根／部件对应、Push 偏移、面组及材质组显隐、独立材质和 UV |
| DAZ Instance／Scatter | 原型、实例及实例组身份、层级、位置、显隐、地面对齐；跟随原型的几何关系 |
| 几何及头发 | 原始内嵌几何、派生来源、面组、顶点／面／UV 索引、细分定义与编辑等级；原文件中的曲线、发丝和控制点数据 |
| 材质与贴图 | 每个表面绑定、所有可编辑材质参数、原 Shader／通道定义、HDR 值、自发光、材质复制／粘贴、预设；原图层／蒙版／色彩空间数据 |
| UV | 每个表面的 UV Set 来源、索引、兼容拓扑、缩放／偏移与还原基线；不同版本的同一路径预设分别保留 |
| 灯光、环境与观察 | 灯光、环境及色调编辑值、组变换；编辑器当前观察角度。原 DAZ 相机、镜头、DOF、IES 和渲染元数据按原文保留 |
| 编辑器扩展 | 生长、年龄、强度、密度、注册状态、收藏及明确取消收藏、对象／实例地面对齐设置 |
| 原生扩展及未知内容 | 动画轨道、时间信息、aniMate、选择集、区域、Push、Typed Channels、未知 `extra` 和未映射材质通道保留原文 |

- **外部安装资产不打包。** DSF、贴图、HDRI 等仍通过内容库／原始资源路径读取；文件保存现有内容库提示，也允许使用当前配置的内容库。它不是包含全部商业资产的独立资源包。外部资产变更仍可能影响结果，结构关系不一致时会拒绝加载。
- **保留数据不代表新增求值能力。** 原来未支持的动画播放、HD、部分材质／模拟扩展等，保留定义但不会因 v2 自动变为可渲染功能。
- **本次排除物理模拟和城市 PCG。** v2 不写入编辑器物理设置、模拟结果或城市配方；原 DUF 自带的扩展元数据仍作为原文保留。已有含城市操作的场景继续沿用旧版保存流程，并在保存状态提示中说明，不把城市悄悄丢弃。旧版明文 DUFEX 仍可读取，普通场景再次保存升级为 v2。
- **写入失败。** 无效数据不替换已有场景；PNG 先写临时文件，场景写入成功后提交。若最后的 PNG 提交失败，会明确提示场景已保存、缩略图需重试。输出文件及解压后的文档各限制为 512 MiB。

## 实施与验收

按“C++ 规则与测量 → 扩展保存／恢复 → Qt 交互”接入。验证小数年龄与强度插值、边界和年龄往返、缩放体积关系、部位封口与标定、两个同名角色隔离、旧参数忽略及保存重开；v2 增加底稿删除后恢复、同路径多版本、惰性 Morph、材质／UV、GeoGraft／Shell／附件、相机、原生文件独立打开及缩略图检查。

已按上述方案实现。普通物体复用当前已求值基础网格，包含 Morph、服装跟随和附件变形；角色在后台独立副本中测量标准站姿。详细验证与边界见 [实施记录](growth_weight_dufex_execution_cn.md)。

未指定启动文件时自动建立空场景，让视口正常刷新。Scale 编辑值以 double 保存，仅在生成渲染矩阵时转换到 float，避免年龄步进出现 `92.00001` 之类尾数。
