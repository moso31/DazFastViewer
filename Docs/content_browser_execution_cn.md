# 内容浏览器：搜索、图标预览与近期使用

日期：2026-09-23。007 后的内容浏览器增强，008 未开始。

## 操作与保存

- 默认使用 112 像素中等图标。鼠标在内容文件区、目录树或近期分类上时，Ctrl＋滚轮调整大小；最小和最大图标仍为 64 / 224 个逻辑像素，中间每 8 像素一档，共 21 档图标，另有一档列表。
- 列表档恢复原来的文件树列表；搜索结果和近期使用采用平面列表。旧版五档配置按实际像素大小迁移，细化档位后保持原来的视觉尺寸。
- 顶部仅保留一行：内容库 / 近期使用下拉切换、项目内容库路径、搜索、`⋯` 菜单。菜单容纳上一级目录、刷新、搜索范围和缩放滑块。移除独立路径行、结果数量 / 耗时 / 索引状态行；空结果提示覆盖在文件区，不另占布局空间。
- 图标格横向只额外保留 8 像素，纵向保留两行文件名和 6 像素余量，格间距为 0。调整图标尺寸时保留当前选择及附近位置，不再反复读取目录。
- 图标大小、当前目录、搜索范围和左右分栏宽度随应用设置保存；主窗口停靠布局继续沿用原有保存机制。设置使用 Qt `QSettings`，不写入资源库。
- 目录树与右侧文件区联动，双击目录进入下一级；菜单“上一级目录”或 Alt＋↑ 返回上级。双击文件或在文件区按 Enter 使用现有 DUF 添加 / 应用流程。
- 文件右键菜单提供添加 / 应用、在内容库中定位及打开资源管理器所在目录。

## 搜索

- 默认搜索全部已配置内容库，也可选择当前内容库或当前目录及子目录。搜索对象是 `.duf` 文件的完整路径，因此名称和任意祖先目录文字都可以匹配。
- 使用忽略大小写的字面包含匹配，不启用正则或通配符；中文路径和 Windows 路径分隔符受支持。
- 输入停止 140 毫秒后自动查询，Enter 立即查询，Esc 清空。历史在 Enter、选择历史项或输入停止 900 毫秒后保存。
- 历史去除首尾空白并按忽略大小写去重，最多 10 项；重新使用的搜索词移到最上方。
- 查询在独立线程中读取不可变路径索引；旧查询被取消后不能覆盖新结果。文件列表采用固定大小项目、分批布局，缩略图不会阻塞搜索完成。
- 首次后台扫描全部内容库并持久化路径索引；再次启动先读取索引，再后台检查目录变化。点击“刷新”立即重扫，运行期间每五分钟重扫一次。当前打开目录另外监听直接变化。
- 扫描期间先查询已有索引，扫描完成后自动更新当前结果；按用户后续要求不再显示独立状态文字。结果中的文件若已删除，打开时由现有加载入口报告错误；刷新索引后清除旧路径。搜索支持的路径范围由“项目 → 项目设置”中的内容库决定。

## 预览

对 `example.duf`，图标依次尝试：

1. `example.duf.png`
2. `example.png`
3. `example.tip.png`
4. `example.duf.tip.png`

悬停预览优先使用两种 `.tip.png`，然后回退到普通图标。图片保持宽高比；缺失或损坏的图片回退到下一个候选或通用文件图标。场景、姿势、形态、材质、参数等 DUF 共用同一预览机制。

图片在两个后台线程中读取并缩小，在界面线程建立 Pixmap；内存缓存限制为 64 MiB，待处理请求限制为 96 个。图标与悬停图分别缓存，刷新时失效，普通缓存最多保留一分钟后重新检查图片。

## 近期使用

- 内容浏览器左上角选择“近期使用”，或通过“文件 → 近期使用…”菜单进入同一界面。
- 左列分类固定以“所有（ALL）”开头，默认选择所有；其后为 Scene、Shape、Pose、Material、Character、Wearable、Light、Camera、Properties、Other。右列复用图标 / 列表和悬停预览。
- 每个分类独立显示最近 20 个不同文件，所有分类合并显示最近 100 个，按最后成功使用的时间倒序。
- 保存集合为“全局 100 项与每类 20 项的并集”，因此连续使用大量材质不会挤掉较早的场景、姿势等分类记录。
- 重复使用同一路径只更新一条记录并置顶。声明类型改变时移入新分类。分类优先采用 DUF `asset_info.type`，无类型声明时按实际场景内容回退；不靠文件夹名称推测。
- 场景后台加载成功后、姿势 / 形态 / 材质等预设应用成功后写入。单纯浏览、预览、选择文件或加载失败均不新增记录。启动文件和“打开场景（替换）”也纳入记录。
- 搜索记录、近期记录跨应用重启保存。进入近期使用时清空内容库搜索词，切回内容库时恢复该搜索词，避免上一页的条件让近期列表意外为空。

## 性能与验证

真实路径：`H:/G1`、`H:/G3`，共 **175,583 个 DUF**。数字为本机本轮实测，初次扫描与索引就绪后的查询分别计时。

| 项目 | 结果 |
|---|---:|
| 首轮建立索引 | 38.824 秒 |
| 再次启动读取持久化索引 | 313 毫秒 |
| 后台复扫（操作系统缓存已热） | 12.404 秒 |
| 8 组查询的异步响应 | 31–63 毫秒 |
| `Genesis 8 Female`，110,905 个结果接入并刷新界面 | 93.3 毫秒 |
| `DTPC03`，120 个结果接入并刷新界面 | 71.4 毫秒 |

界面计时从 Enter 提交到结果模型更新并处理界面事件；缩略图继续异步加载，不将所有结果图片解码计入搜索完成。自动输入模式另有 140 毫秒防抖。首次扫描前没有完整索引，不能将首次完整建库也声明为一秒内完成。

验证覆盖：分类配额互不挤占、路径与搜索去重、重启恢复、类型识别、重叠内容库、Unicode、字面匹配、目录边界、过期搜索取消、扫描切换取消、缓存恢复、新增 / 删除刷新、真实缩略图读取、Ctrl＋滚轮及键盘激活。已有 13 项工程测试与新增 `content_browser` 共 14 项通过；上游 `cycles_version` 依赖未部署的 `out/cycles.exe`，不属于本项目 `tools/build.ps1` 的工程验证集合。

副屏独立浏览器验证使用真实场景缩略图和 DTPC03 姿势，证据保存于 `artifacts/content-browser/`：`icons.png`、`search.png`、`recent.png`、`tooltip.png`；性能记录为 `search-benchmark.json`、`search-benchmark-warm.json`。副屏浏览器验证使用临时设置文件，不写入用户的近期记录。
