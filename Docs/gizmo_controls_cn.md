# 节点 Gizmo 与模块化顶部栏

2026-09-25。新增平移、旋转和缩放手柄，并将应用标识、菜单与 3D 工具合并到窗口顶部。追加平面平移、IK 回退、独立坐标系记忆与角色地面对齐。

## 使用

- 单选模型、角色、骨骼或灯光，点击顶部的平移、旋转或缩放图标，在视口拖动相应手柄。
- 红、绿、蓝分别代表 DAZ 的 X、Y、Z 轴。`Local` 沿节点当前自身坐标轴操作；`World` 沿固定世界坐标轴操作。两种模式均围绕节点自身轴心旋转。
- 旋转环中心显示带深色描边的白色菱形锚点，仅指示旋转轴心，不增加点击或拖动功能；大小随 DPI 缩放。
- 平移除了三条轴，还支持 XY、XZ、YZ 平面方块；拖动方块内部或边框即可在该平面内移动。与视线近乎平行的平面隐藏，避免手柄退化。
- 平移与旋转分别记忆自己的 `Local`／`World` 状态；切到选择、缩放或另一个工具再返回时，恢复该工具最后的选择。
- 缩放使用本地轴。轴末端方框用于单轴缩放，中心方框用于等比缩放；缩放时坐标模式显示 Local。
- 拖动显示基础网格代理，松手提交并恢复完整渲染。Esc、视口失焦、选择变化、相机或场景版本变化会取消当前拖动。回到按下位置不会留下参数残差。
- 任意 T／R／S 模式下，手柄优先命中；未命中手柄时继续原有左键 IK 逻辑，仍要求事先单选当前角色。没有命中 IK 时保留普通选取。相机的鼠标和 WASDQE 操作继续可用。

骨骼变换遵守已有通道的可编辑状态、锁定与限位，使用原生旋转顺序；无法完全达到指定方向时保留可达结果。此处为直接 FK 节点编辑，沿用属性面板的语义，不自动执行 IK 固定点补偿。当前 Gizmo 面向单选的现有可编辑节点；多选、纯组织分组和只读散布实例不显示手柄。

## 顶部布局

左上角应用图标固定，右侧保留最小化、最大化／还原和关闭按钮。菜单模块、3D 操作模块和角色功能模块拥有独立拖动把手，默认同一行，可重新排序、换行、浮动或隐藏。角色功能模块默认位于 Local／World 右侧，包含小人向下落地的图标和比例输入，后续功能可在此扩展。

从“视图”或应用图标菜单可重新显示模块、恢复顶部默认布局。“恢复默认布局”同时恢复停靠面板与顶部模块。退出时保存顶部模块状态，下次启动继承；原有 PowerPose 模板页和停靠布局继续使用原设置键。

窗口使用系统拖动与边缘缩放命中区域，双击顶部空白可最大化／还原，最大化限制在当前显示器工作区。实现参考微软的[自定义窗口框架文档](https://learn.microsoft.com/en-us/windows/win32/dwm/customframe)，未引入额外 GUI 或 Gizmo 库。

## 对齐到地面

单选角色、其骨骼或已绑定附件后，通过角色功能模块的小人向下图标、“编辑 → 对齐到地面”或 `Ctrl+D` 执行。每个角色拥有独立的“地面对齐比例”，默认 0；修改比例本身不移动角色，点击对齐才生效。输入框中刚输入但尚未回车的数值，也会在点击时提交。

用角色当前姿势、形态、旋转和缩放求值后的世界 AABB 计算：

```text
H = maxY - minY
沿 DAZ 世界 Y 的位移 = 地面对齐比例 × H - minY
```

例如 0 使底部贴地，0.01 使底部高于地面当前角色高度的 1%，负值使底部下沉。这里的 Y 是 DAZ 的世界竖直轴（内部 IR 为 Z 向上）；即使父节点有旋转和缩放，也只沿世界竖直方向移动，不改变角色姿势、旋转或缩放。等待中的姿势／变换更新完成后才读取包围盒，重复对齐不累积偏移。

比例属于当前场景中每个角色的操作设置：切换选择、追加其他角色、刷新参数目录、删除其他角色时保留；重新打开场景默认 0，未新增 DUF 写回功能。T／R 的坐标系记忆保留在本次运行期间。
