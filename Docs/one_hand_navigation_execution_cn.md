# 视口单手操作与聚焦联动

日期：2026-09-23。007 后交互修复，008 未开始。

## 当前操作

| 操作 | 功能 |
|---|---|
| 右键拖动 | 保持原有环绕 |
| Shift＋右键拖动 | 恢复原有屏幕方向平移 |
| Ctrl＋右键拖动 | 第一人称转头，相机位置固定 |
| 中键（按住滚轮）拖动 | 屏幕方向平移，与 Shift＋右键相同 |
| 后侧键拖动 | 第一人称转头，与 Ctrl＋右键相同 |
| 后侧键单击 | 与 F、Hierarchy 的聚焦菜单共用当前选择 |
| 滚轮滚动 | 原有缩放 |

单手操作默认启用，无需切换模式。后侧键采用 Windows 的 `XBUTTON1`（后退），前侧键 `XBUTTON2` 不触发相机功能。

## 单击与边界

后侧键按下时只建立候选单击，不立即聚焦。移动达到系统拖动阈值后才开始转头；松开时要求未拖动、未混用键盘或其他鼠标按键、按下和松开均在视口内。轻微抖动仍可单击，但拖远再回到起点不会误判成单击。

组合操作、滚轮、离开视口、捕获丢失和失焦均取消候选单击。后侧键与 F 组合也不会触发独立 F 聚焦。视口外按下、外部释放、外部滚轮及 Hierarchy 区域侧键不会改变相机。导航仅由原生视口接收，不注册全局鼠标快捷键。

Hierarchy 菜单、F 和后侧键统一调用 `focus_selection()`，保留当前所选角色、部位或灯光的聚焦语义。当用户刚切换层级选择、渲染线程尚未更新对应包围盒时，聚焦请求等待该选择同步，避免丢失请求或使用旧对象的包围盒。

低分辨率预览沿用上一轮：持续导航保持宽、高各 1/4、最多 2 样本，结束后恢复完整分辨率；滚轮及聚焦先预览再细化。中键与后侧键拖动均接入同一输入状态，多个导航输入重叠时不会因释放其中一个而提前恢复完整采样。
