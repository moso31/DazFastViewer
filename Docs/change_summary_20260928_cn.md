# 2026-09-28 本地修改汇总

本次汇总涵盖基于 `2af44ed` 的全部未提交源码、测试、构建脚本与文档改动。

## 大场景加载优化

- 最多四个工作线程预取资源文档，共享几何、参数和骨架阶段的只读解析结果；按文件版本检查失效，合并并发重复读取，缓存淘汰在锁外释放大文档。
- Morph 元数据分批保留句柄，按独立资产并行发现参数；场景覆盖和节点索引只建立一次，结果按原顺序合并。
- 增加内嵌 Morph 差值专用视图与缓存，避免为多个参数重复解码整个场景；缓存路径解析和 Modifier 设置，减少 JSON 数组复制。
- 并行计算服装表面绑定、蒙皮顶点和渲染细分；凹凸贴图面积改为一次按材质累计，复用图像尺寸查询。

## 场景加载兼容性修复

- 重建 Geometry Shell 及关联 GeoGraft 部件，保留材质、UV、显隐和 Push 偏移，在宿主形变后更新壳层；维护追加、独立复制和删除时的引用。
- 允许有参考顶点但没有可绘制面的容器不带材质槽，继续拒绝有可绘制面却缺材质的无效网格。
- 将相同轴、归一化的柔性 Local 权重转换为线性蒙皮，修复目标场景 Rope 的加载阻塞；没有宣称完整支持所有 TriAx。

`5b.duf` 与 `9/1.duf` 已从加载失败变为实际编辑器显示成功。`17.duf` 再次打开首帧从约 215 秒降到 87 秒，空应用缓存约 165 秒；其余代表场景约 64～82 秒。**尚未全面达到 60 秒目标**。测试保留原画质，缓存、视口尺寸等比较条件与数据一致性校验详见[优化报告](scene_loading_optimization_cn.md)。这些性能数据来自锐化功能加入前的加载优化版本，不能当作高强度锐化的性能测量。

## 视口锐化

- 位于“项目 → 项目设置 → 渲染 → 界面与视口”，使用水平滑块，范围 **0.00～20.00**，右侧显示两位小数。
- 默认 0.00 关闭；方向键微调 0.01，翻页键调整 0.10。保存小数偏好，自动换算旧百分数配置。
- 在 GPU 显示阶段增强局部对比度，并限制邻域范围以抑制光晕；支持原分辨率及双线性、双三次升采样。
- “应用”更新当前显示，“保存”持久化，“取消”丢弃未应用的修改。调整强度不重建渲染会话，不清空采样，不改动模型、材质和源贴图。

## 诊断、测试与构建

- 增加场景盘点及顺序测量脚本，记录独立缓存、可执行文件哈希、进程资源、CPU 阶段和真实编辑器首帧；扩展 CPU 诊断入口以包含活动 Morph 差值准备。
- 新增 Geometry Shell 回归并纳入构建脚本；补充缓存并发及失效、Local 权重姿势、锐化设置保存与迁移、GPU 像素结果及采样保留检查。
- 新增加载调研、实施与性能报告，更新项目设置文档和 README 入口。构建产物、缓存、截图及原始测量记录保存在本地忽略目录，未将用户场景资产纳入版本库。
