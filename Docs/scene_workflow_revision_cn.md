# 场景工作流改造：调查与实施方案

日期：2026-09-21。状态：用户已确认并授权实施，代码及验证进度见 [执行报告](scene_workflow_execution_cn.md)。此任务插入 007 与 008 之间，008 尚未开始。

本轮以用户提出的多对象场景、DUF 复合语义、二级选取和可停靠视口为目标，不沿用此前“所有非姿势 DUF 都替换当前模型”的假设。原 007 的求值能力继续复用，不将本轮混同于原计划中的 FK / IK。

## 已核实的现状

- `src/editor/main.cpp` 的 `open_asset()` 仅区分 `preset_pose`，其他类型全部进入 `load()` 并替换当前文档。
- 骨骼树的所有节点只保存角色的 target 索引，没有独立骨骼身份；选择头部和选择角色得到相同参数面板。
- `src/viewport/window.cpp` 尚无左键选取逻辑。视口宿主固定为 960×720，位于中央控件中；编辑器未持久化停靠布局。
- `src/editor/renderer.cpp` 为每份文档添加预览灯光；`src/daz/loader.cpp` 对 DAZ 灯光、相机只生成未导入警告。
- loader 会共享相同几何的网格，但 `MorphRuntime` 要求可编辑对象拥有独立网格。重复载入同一个角色需要解决实例独立变形问题。
- `src/daz/morphs.cpp` 在每个 Morph 的处理过程中，通过 JSON `value()` 复制场景与 modifier 列表并遍历，随后解析覆盖资源路径。这是大场景的潜在高额开销，尚未通过运行采样确认具体耗时。

## 实施边界与行为

1. **场景文档与对象身份。** 保存多个角色、普通模型及灯光。资产定义身份和场景实例身份分离，重复载入同一角色时 Morph、Pose、变换互不串扰；补齐父子节点与骨骼身份。共享不可变资源，隔离可编辑变形数据。
2. **DUF 统一分派。** 根据类型及内容生成操作：角色与道具添加到现有场景；完整 scene 提供打开与合并语义；pose、shape、材质预设作用于选中目标。未知类型明确报告，不静默当作模型。移除“姿势”菜单，以内容浏览器和统一 DUF 入口应用预设。
3. **预设按通道应用。** pose 只更改文件声明的目标角色姿势及相关控制器；shape 应用声明的形态通道，包括显式零值。两者不得重建场景或重置灯光、相机及其他对象。参数按 URI、所属节点及实例解析，不能只按显示名匹配。未支持通道显示具体原因。
4. **场景加载。** 对场景覆盖建立一次性索引，缓存解析与资源查找，避免每个参数重复复制整个场景。显示解析、资源、Morph、骨架、公式和渲染准备阶段；错误退出等待状态，保留上一有效文档。核实 scene 中保存的实例、形态、姿势、材质和灯光是否正确还原；不以自动预览灯光代替文件灯光而不告知用户。
5. **选取。** 使用当前 Morph / Skinning 求值后的网格进行遮挡正确的射线命中。普通模型一次选中；角色首次命中选择整体，后续命中同一已选角色时选择命中部位。换角色重新选择整体；点击空白清除选择。层次树与 viewport 共用选择状态。
6. **部位参数。** 保留几何多边形组、节点归属和骨骼关联，建立命中部位映射；不只按离骨骼中心的距离猜测。头部等节点以真实参数 owner、alias 与 DAZ 分组提供对应 Morph，验证 Jaw Open 等参数实际改变目标角色。
7. **悬停覆盖。** 增加独立的视口覆盖绘制阶段，基于当前可见几何生成深度正确的对象遮罩，再以淡黄色混合。不得修改原材质；悬停移动不得触发 Morph / Skinning 或重启 Cycles 累积。蒙皮变化、遮挡、鼠标离开及对象切换都更新遮罩。
8. **停靠与分辨率。** viewport 成为可停靠、可浮动面板，默认居中。窗口尺寸及 DPI 变化同步宿主、原生子窗口、Cycles buffer、相机宽高比和选取坐标。通过渲染线程处理 resize，最小化与零尺寸不创建无效 buffer。
9. **布局继承。** 持久化窗口与面板位置、尺寸、可见性及停靠状态，使用稳定标识和布局版本；处理屏幕变化后不可见的窗口，并提供恢复默认布局。测试仍遵守只在副屏运行的约束。

## 验证与交付标准

- 工程测试验证 DUF 分派、scene modifier 索引、实例隔离、预设局部修改、部位参数映射、射线前后遮挡及变形后命中。
- 加载同一角色两次及普通道具和灯光；只对其中一人应用 pose / shape，检查另一人和场景设置完全保留。
- 实际加载 `test2.duf`，记录各阶段结果、依赖缺失和未支持项；不得把仍在等待、仅基础网格或替代灯光称为完整通过。
- 对选中角色应用 `face_08.duf`，逐通道记录应用和未应用结果，验证非零形态及显式归零；保持其他对象状态。
- 副屏验证角色两级点击、层次树双向同步、头部 Jaw Open、淡黄色悬停及遮挡正确性。
- 副屏验证停靠、浮动、拖动缩放、最小化恢复以及重启后的布局和实际渲染分辨率。
- 运行与改动相关的现有 Morph / Skeleton / Formula 回归；不重复无关性能回放。不将工程测试代替 DAZ Golden。
