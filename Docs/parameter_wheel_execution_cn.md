# 参数滚轮选择与小数精度修复

2026-09-25：对象属性与 Morph 参数列表的滚轮调参只作用于左键明确选中的参数行。

## 使用方式

- 左键点击参数名称、Slider 或数字框后，该行显示选中状态。鼠标在该行的 Slider 或数字框上滚轮可调整数值。
- 鼠标移到其他参数上时，滚轮用于翻页，不修改悬停项，也不修改之前选中的项。
- 仅获得焦点、键盘／程序选择、右键点击不会开启滚轮调参。切换对象、重建参数列表或筛选隐藏该行后，需要重新左键选中。
- 参数因滚动离开视口再返回时，保留该行的选中状态。枚举、日期和时间控件遵循相同规则，禁用参数不阻断翻页。

## 精度修复

Slider 原本直接对回读的 float 数值累加步长，连续滚动会累积二进制误差。现在将滚轮交给同一行的数字框处理，与数字输入的十进制步进、范围和滚轮刻度累积保持一致；拖动仍使用原有相对距离算法。

`tests/parameter_wheel.inl` 通过长列表与真实 Qt 滚轮事件验证选择和翻页规则，覆盖文本框内部编辑区、虚拟行重建、绑定切换、同事件多个刻度及高分辨率滚轮。精度用例包含 `100.01 → 100.51 → 100.01`、float 百分比换算和 `0.123456 → 0.123457`，同时检查保存值与显示文本。
