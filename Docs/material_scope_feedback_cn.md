# SteelcoreCrate 材质调参与作用域修正

2026-11-14。使用 `H:/G1/Scenes/test3.dufex` 中的 SteelcoreCrate，以及 `H:/G1/Scenes/test.dufex` 中的角色场景。

## 透明效果的实际原因

M01 的折射、裁切和实时材质覆盖可以生效。保存场景中 M01 的折射权重为 1，但折射粗糙度为 0.5，折射颜色为线性 RGB 约 0.4915（显示值约 0.73）；这些值继承自应用过的加权高光预设，再叠加用户编辑。

另外，M07 有三张内部大面。只把 M01 变透明，仍会看到后面的不透明内板。分别渲染原样、低粗糙度、裁切、单独保留 M01，以及 M01/M07 同时设为玻璃后确认了这一点。

可复用的效果副本位于 `artifacts/material-scope/glass/glass-M01-M07/scene.dufex`。M01 和 M07 使用独立折射层、折射权重 1、折射颜色 RGB 1、粗糙度 0.03、IOR 1.5，保持源材质的薄壁设置。其余表面保留金属外观。用户原文件没有改写。

本次没有更换着色模型或修改既有材质的渲染算法。

### 非薄壁折射补测

上面的玻璃副本始终保持 `Opacity = 1`；裁切只用于定位内板遮挡，不是玻璃效果的实现方式。

进一步对 M01/M07 固定 `Opacity = 1`、无透明度贴图、独立折射层、IOR 1.5、白色折射颜色和粗糙度 0.03，分别以 512 样本渲染薄壁开启、薄壁关闭，以及关闭薄壁但将折射权重归零的三个阶段：

- 开启、关闭薄壁时，折射权重 1 都能看见内部网格；关闭薄壁后，内部网格的折射偏移明显不同。
- 同样保持 Opacity 1，将折射权重改为 0 后恢复不透明，确认透光来自折射。
- 非薄壁效果副本：`artifacts/material-scope/refraction/solid-refraction/scene.dufex`；对应图像 `smoke.png`、实际参数 `materials.json`，完整对照见上级 `report.json`。

薄壁不是实现玻璃的必要开关，但它会影响光线穿过表面的折射路径，因此两种模式的画面不应被要求完全相同。此次补测无需修改程序代码。

## 编辑体验

- 普通连续材质参数默认步长为 0.05。源文件更细的步长继续采用；源权重步长 1 降到 0.05，亮度、色温等有单位的专用步长保留。用户显式保存的范围和步长仍有最高优先级。直接输入不按步长取整。
- 毛发开关移入毛发分类，普通物体默认收起该分类；启用毛发的材质默认展开。关闭毛发时，对应专用参数不可编辑。
- “皮下散射”改为适用于道具和角色的“次表面散射”。应用设置关闭 SSS 时，标题显示“设置已禁用”并默认折叠；保留参数以便预先配置，重新启用设置后生效。
- 独立折射层关闭时，独立颜色和粗糙度控件禁用，并说明共用输入的来源。折射权重提示包含粗糙度、颜色与内部表面遮挡的关系。
- 滚轮仍需先点击选中参数行，其他位置滚动外层页面。选中提示仅作用于标签，不修改数值框或箭头样式。

## 源通道说明

只读信息区分别显示源通道、源值和转换状态。悬停可查看对应编辑参数的当前值，包含预设及编辑覆盖；颜色以线性数值显示。

状态区分已转换、仅数值已转换、源输入/源模式未采用、当前未启用、未启用层但尚未支持、说明/预览信息、未支持。例如，共用高光输入时，单独保存的 Refraction Color 不是导入时采用的颜色；清漆权重为零时，其各向异性数值不会生效。非零源值本身不等于渲染实现。

本次没有宣称实现完整 Iray Uber。金属薄片、部分清漆属性等尚未实现的通道仍明确标记为未支持，并保留源数据。
