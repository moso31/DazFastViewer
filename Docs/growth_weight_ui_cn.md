## 2026-11-13 体格与肥胖解耦

正式生长模块采用已确认的角色预览方案。肥胖位于体格下面、倍率左侧，与倍率同一行；默认值 0.5，固定步进 0.125，沿用体格的原生数值框、标签选中提示和点击选中后滚轮调参。可以直接输入负数或大于 1 的值，最终 Morph 写入仍遵守资产本身的限位。

令 `T(age, x)` 为原有五档体格表的年龄／档位插值，全部 19 项先取 `T(age, 0.5)`，再按以下规则替换：

| 控制项 | Morph 与计算 |
| --- | --- |
| 体格 `strength` | `GHD Width`、`Foot Propagating Scale`、`Hand Propagating Scale`、`Foot Length`、`All Toes Length` 使用 `T(age, strength)` |
| 肥胖 `fatness` | `Body Size`、`Voluptuous`、`Glutes Size`、`BGM Big Girl Pear Shape` 使用 `T(age, fatness)` |
| 胖瘦补充 | `Weight = T(age, 0.5).Weight + fatness - 0.5`；正向由原资产 ERC 驱动 Heavy，负向驱动 Thin |
| 年龄成熟度 | 其余通道保持 `T(age, 0.5)`，包括头部、青春期和乳房发育参数 |

两个轴均为 0.5 时精确复用旧表中档。体格仍遵循原年龄曲线，低龄段部分档位相同；肥胖的 Weight 偏移补足该段胖瘦差异。婴儿期混合在上述计算之后继续使用原来的 Baby 权重；生长曲线启用时，Morph 年龄仍截止于“规划到年龄”。

肥胖以对象扩展字段 `fatness` 保存到 DUFEX，随复制、撤销和重做恢复。旧文件缺字段时取 0.5，打开时不重新计算已保存的 Morph；之后修改年龄、体格、肥胖或其他要求重算形体的生长选项时应用新规则。旧版非中档体格的外形不会被承诺映射为新参数的完全等价组合。

独立预览工具与正式版共用同一套三参数算法，旧规则仅保留作对照。实际场景对照使用 `H:/g1/Scenes/test8.duf` 及已确认预览的报告，逐项比较 19 个 Morph；验证产物位于 `artifacts/growth-composition-integration/`。

## 2026-11-08 加载阶段优化

- 96／192 次位移处理发生在首次形变和后续调参中，DUFEX 读取／操作恢复阶段本身没有执行这两组循环。恢复穿戴关系时原先为每次操作构建完整形变运行时，重复生成全场景的最近点绑定、附件邻接和胸腹权重；高面数头发的绑定在同一次加载中可能重复初始化 16 次。
- 穿戴操作改用校验准备模式：仍逐次检查 Fit To 解析与循环、兼容基型／Clone、骨骼、GeoGraft 接缝和拓扑、刚性跟随及碰撞目标，并维持后续操作需要的关系。跳过只供实际形变使用的逐顶点投射、胸腹权重和旋转邻域缓存，渲染准备时统一构建。校验模式的运行时禁止用于形变求值。

## 2026-11-07 生长曲线修订

- 成年边界可自由设置为正数，例如 8 或 25；阶段之间至少相隔 0.001。调整成年边界会等比例伸缩阶段时间，同时反向缩放基础速度以保留额外增长总量。最低增长不随之缩放，始终累计至成年边界，然后立即停止。曲线模式中的年龄形变也在该边界冻结；年龄字段仍保留原输入。

- “按端点拟合”以出生 Scale 和成年 Scale 为目标，重建参考阶段并估计 A，不自动修改 B。B1 先从总增长中扣除 `18 × B`，再分配其余增长；若剩余量为负则提示无解并禁止提交这次失败操作。剩余量为零时退化为匀速，模板 A 不再具有唯一峰值含义。B2 先拟合两端，再叠加 `B × min(年龄,18)`；成年结果比目标增加 `18 × B`。图表明确显示“成年结果”。
- 拟合是显式操作。拟合完成后，出生 Scale、A、B 或阶段速度的进一步编辑可以改变成年结果；“成年 Scale（拟合目标）”仅用于下一次拟合。B 在 18 之前始终有效，在 18 直接停止，允许增长速度在成年边界突变。阶段表显示包含 B 的总增长，成年边界前的增长为 B，18 及以后为 0。

## 2026-11-07 婴儿期衰减

- 年龄支持 0～20 岁和小数。“启用婴儿期衰减”作为长期功能保留，默认不勾选并隐藏详情。启用后显示“起始强度”“衰减起始年龄”“衰减结束年龄”及混合开关。默认值依次为 **0.6、0 岁、7 岁**，即 Baby 强度在 0～7 岁从 `0.6 → 0` 线性衰减。起始年龄处及以下采用起始强度，结束年龄处及以上为 0；区间必须满足 `0 ≤ 起始 < 结束 ≤ 20`，强度范围 0～1。修改后立即预览，关闭后隐藏详情并保留配置。
