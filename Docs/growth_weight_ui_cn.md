# 生长面板、测量单位与默认空场景

2026-09-26。

- 生长控制改为两行：`年龄／步长`、`体格／每年增长／−／＋`。年龄的滚轮和上下箭头均跟随当前步长，支持小数；右侧 −／＋只调整缩放。移除“应用当前年龄”。
- 汇总字号增加，身高、体重标签加粗。移除体积、标定段和网格提示行；详情默认收回，按手臂（上臂、前臂）、腿（大腿、小腿）、手（五指）、脚排列，主要部位加粗，不使用表格。对称肢体只统计一侧的 13 项部位，固定取左侧作为代表，名称不带左右；详情显示单侧重量，全身体重仍按完整模型计算。
- “编辑 → 测量单位…”设置全局倍率，默认 1×，作为应用偏好记住，不写进某个角色。修改立即刷新汇总与部位重量，不修改模型或触发几何求值。
- 身高乘以倍率；体重和各部位重量乘以倍率的立方。身高低于 10 m 使用 cm，低于 10 km 使用 m，其余使用 km；重量低于 1 kg 使用 g，低于 1 t 使用 kg，其余使用 t。
- 测量显示最多两位小数，省略末尾零。倍率和立方乘法采用十进制有效位运算；不经过浮点倍率转换。极大读数及当前单位下不足 0.01 的非零读数使用科学计数法，避免显示为无穷或零。输入支持最多 128 字符，科学计数指数范围为 −10000～10000。
- 对象 Scale 的编辑值改为 double，序列化同样保留 double；派生缩放在底层 float 的有效精度内清理尾数，再进行年龄步进运算，用户输入的 double 倍率保持精度。生成渲染矩阵仍使用引擎原有 float 范围。
- 未指定启动文件时创建并提交空场景，立即初始化视口渲染。首次从内容库导入保留正常预览灯光流程；已有对象或环境编辑时继续追加。
- 参数星标的收藏和取消收藏随 Ctrl+S 写入 `.dufex`，按对象、骨骼、参数分别恢复；灯光及环境／色调参数星标也保存。打开尚无收藏记录的旧场景时迁移本机旧记录；已有 `.dufex` 记录优先，不被本机设置覆盖。

## 验证

`GrowthWeightTest` 覆盖单位边界、十进制舍入、线性／立方关系、`1e2000`／`1e-2000` 和无效倍率；新增 90 + 2 = 92 的精度检查。`ParameterControlsTest` 实际发送滚轮／步进事件，验证两行布局、折叠、粗体、全局倍率及对话框。

完整工程回归及真实角色、空场景验证记录放在 `artifacts/growth-ui/`，工程回归日志为 `artifacts/growth-ui-ctest.log`。真实场景检查包括 Scale 显示、保存重开、详情排版，以及修改测量倍率后几何更新次数不变。

最终证据为 `character-release/` 与 `empty-release/`。早期 `character/` 只检查增长差值，未捕获载入时已有的 Scale 尾数，不作为精度通过的证据。最终检查要求实际控件显示 `90`、`92`。

收藏保存与单侧部位的后续回归记录位于 `artifacts/favorites-weight/`，其中 `ctest.log` 为 23 项工程检查，`character-release/` 为双角色／道具的真实界面保存重开检查。
