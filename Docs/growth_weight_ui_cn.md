# 生长面板、测量单位与默认空场景

## 2026-11-07 婴儿期衰减

- 年龄支持 0～20 岁和小数。“启用婴儿期衰减”作为长期功能保留，默认不勾选并隐藏详情。启用后显示“起始强度”“衰减起始年龄”“衰减结束年龄”及混合开关。默认值依次为 **0.6、0 岁、7 岁**，即 Baby 强度在 0～7 岁从 `0.6 → 0` 线性衰减。起始年龄处及以下采用起始强度，结束年龄处及以上为 0；区间必须满足 `0 ≤ 起始 < 结束 ≤ 20`，强度范围 0～1。修改后立即预览，关闭后隐藏详情并保留配置。
- “与原生长参数混合（lerp）”默认开启：Baby 权重为 `b` 时，原有 19 项生长表输出乘以 `1-b`，Baby 控制器设为 `b`。关闭后两套形变叠加，便于比较是否需要混合。其他角色自定义 Morph 不参与此次混合；0～1 岁的旧表使用第一列，避免表格越界。
- 本机 Sixus1 资产的控制器同时驱动 `G8Baby_Shape` 和 `G8Baby_Scale`。后者通过 ERC 向根节点等比缩放加上 `-0.75 × Baby`，在已缩小的角色上可能得到负值。首次启用婴儿期后，只隔离 `G8Baby_Scale` 写根缩放的公式，保留形体、骨架中心／末端、姿势修正及正常附件跟随。实际尺寸仍由现有“每年增长”、Scale 和倍率控制；因此这里的 Baby=1 表示完整婴儿形体，不采用资产附带的固定缩小量。关闭后清零 Baby 并恢复原生长表输出，保留缩放隔离；从未启用的角色不会接管手工 Baby。
- 年龄变化继续使用现有的实际 Scale 百分点增减，并补偿其他生长 ERC 引起的根缩放。单独调整衰减区间或混合开关保持实际 Scale。无效区间、非有限数值、非正骨骼缩放和会把实际 Scale 减到零以下的操作整次拒绝，保留之前的年龄、Morph 和变换。如果原本的尺寸与每年增长组合不能到达 0 岁，需要先调整 Scale 或每年增长。
- 仅打开场景或添加生长模块不改变当前形体。启用状态、参数、混合开关和缩放隔离状态按对象保存到 DUFEX，随复制、撤销／重做恢复。旧文件缺少启用字段时默认关闭，缺少数值字段时采用上述默认值，保留打开时已有形体，主动编辑生长时才应用。未提供可用 Baby 的角色保留原生长形变，仅在启用衰减且权重大于 0 时提示缺少 `Genesis 8 Baby`。
- 数值控件使用共享范围／精度设置，须先点击选中才接受滚轮；关闭详情后清除该行选择，内容由外层页面滚动。

材质的“浏览图像文件”从当前参数的有效贴图目录打开，包含已替换但尚未保存的贴图；多选时使用第一个存在目录的贴图。无贴图或目录不存在时沿用文件对话框默认目录。

## 2026-10-11 修订

- 身高测量保留当前 Morph，隔离 geograft、服装和其他对象，使用细分 0 的原皮，在归零骨骼姿势下计算身体竖直轴最高点与最低点之差，计入当前缩放。旧实现会在测量副本上重新套用年龄／体格表，导致测量形体与当前角色不一致；已移除这一步。
- 新增独立“倍率”行：默认 1，步进 0.05；×／÷ 点击时乘除当前角色 Scale 百分数，不联动年龄、体格、每年增长或位置。倍率设置本身不修改 Scale。
- `round` 点击启用／关闭，悬停编辑取整位数，只有 OK 提交。默认对齐到十位（175% → 180%）；位数为 10 的指数，0 表示整数、−4 表示小数点后四位，支持至 −9，正方向不设业务上限。若取整导致零或数值溢出，则保留原 Scale 并提示。倍率与取整设置随角色保存、复制和撤销恢复。
- “编辑 → 复制选中对象”复制模型及其骨架；“复制选中对象及其子对象”另包含子级与绑定附件。副本初始位置与原件相同，拥有独立身份、几何、材质和参数；同次复制的内部引用指向副本，未复制的外部父级保持原绑定。
- 内容浏览器增加“搜索”模式，输入关键词自动切换；内容库、近期使用与搜索结果互相独立，清空回到内容库。每类近期资源上限为 50，全局 ALL 仍为 100。搜索框右侧原生清空按钮纳入工程 UI 规范，参数搜索框已补齐，材质搜索框沿用现有实现。

2026-09-26。

- 生长控制改为两行：`年龄／步长`、`体格／每年增长／−／＋`。年龄的滚轮和上下箭头均跟随当前步长，支持小数；右侧 −／＋只调整缩放。移除“应用当前年龄”。
- 汇总字号增加，身高、体重标签加粗。移除体积、标定段和网格提示行；详情默认收回，按手臂（上臂、前臂）、腿（大腿、小腿）、手（五指）、脚排列，主要部位加粗，不使用表格。对称肢体只统计一侧的 13 项部位，固定取左侧作为代表，名称不带左右；详情显示单侧重量，全身体重仍按完整模型计算。
- “编辑 → 测量单位…”设置全局倍率，默认 1×，作为应用偏好记住，不写进某个角色。修改立即刷新汇总与部位重量，不修改模型或触发几何求值。
- 身高乘以倍率；体重和各部位重量乘以倍率的立方。身高低于 10 m 使用 cm，低于 10 km 使用 m，其余使用 km；重量低于 1 kg 使用 g，低于 1 t 使用 kg，其余使用 t。
- 测量显示最多两位小数，省略末尾零。倍率和立方乘法采用十进制有效位运算；不经过浮点倍率转换。极大读数及当前单位下不足 0.01 的非零读数使用科学计数法，避免显示为无穷或零。输入支持最多 128 字符，科学计数指数范围为 −10000～10000。
- 对象 Scale 的编辑值改为 double，序列化同样保留 double；派生缩放在底层 float 的有效精度内清理尾数，再进行年龄步进运算，用户输入的 double 倍率保持精度。生成渲染矩阵仍使用引擎原有 float 范围。
- 未指定启动文件时创建并提交空场景，立即初始化视口渲染。首次从内容库导入保留正常预览灯光流程；已有对象或环境编辑时继续追加。
- 参数星标的收藏和取消收藏随 Ctrl+S 写入 `.dufex`，按对象、骨骼、参数分别恢复；灯光及环境／色调参数星标也保存。打开尚无收藏记录的旧场景时迁移本机旧记录；已有 `.dufex` 记录优先，不被本机设置覆盖。

## 验证

`GrowthWeightTest` 覆盖单位边界、十进制舍入、线性／立方关系、`1e2000`／`1e-2000` 和无效倍率；新增 90 + 2 = 92 的精度检查。`ParameterControlsTest` 实际发送滚轮／步进事件，验证两行布局、折叠、粗体、全局倍率及对话框。

收藏保存与单侧部位的后续回归记录位于 `artifacts/favorites-weight/`，其中 `ctest.log` 为 23 项工程检查，`character-release/` 为双角色／道具的真实界面保存重开检查。
