# 视口移动预览与第一人称转头

日期：2026-09-22。属于 007 后交互修复，008 未开始。

> 后续操作映射已按用户反馈调整：Shift＋右键恢复平移，Ctrl＋右键为第一人称转头，并增加中键和后侧键操作。本文下方保留首轮实现与验证记录，当前映射见[单手操作报告](one_hand_navigation_execution_cn.md)。

## 行为

- 编辑器移动预览采用宽、高各 1/4 的渲染缓冲，总像素约为完整视口的 1/16，最多累计 2 个样本，再放大到视口显示。非整除尺寸向下取整，最小为 1 像素。
- 右键环绕、Shift＋右键转头和 WASDQE 按住期间维持预览。多个输入重叠时，必须等所有移动键及右键释放，才恢复完整渲染。按住右键但鼠标暂时静止也保持预览。
- 滚轮、F 聚焦和程序设置视角统一经过相机快照。新视角至少先输出一帧预览，距离最后一次即时输入静止 150 毫秒后恢复完整分辨率；即使输入处理延迟超过该时间，也不能直接跳过新视角的预览。
- Shift＋右键从平移改为第一人称转头：相机位置固定，改变观察方向；WASDQE 继续负责位移，Shift 保留加速。
- 失焦、取消鼠标操作会释放导航状态；鼠标捕获丢失会结束右键导航，但保留仍按着的移动键。

静止后重新从完整分辨率累计样本，沿用当前正式采样设置（默认上限 4096、蓝噪声、自适应阈值 0.01、关闭降噪）。预览不修改材质或光线反弹配置。

## 实现

原实现每次相机移动仍按完整尺寸渲染，并等待上一视角呈现后才应用下一视角。现在仅在从完整渲染进入预览时允许提前请求取消旧工作；预览帧之间继续合并最新相机输入，等待当前帧呈现，避免连续重置导致始终没有图像。

OpenGL 显示缓冲仍按完整视口分配，按每个帧槽实际尺寸上传和缩放采样，保留 GPU interop。完整图和预览图可以在切换期间共存，不因降分辨率反复创建 Cycles 会话或重建场景。移动期间暂缓悬停射线及覆盖绘制；静止后恢复。

本次动态质量切换用于 Qt 编辑器；独立基准程序保留原分辨率和采样口径，共享的 Shift＋右键输入及操作提示同步更新。没有运行固定性能回放，也不将减少像素量等同于帧率提升倍数。

- 副屏小场景交互检查通过：W/A/S/D/Q/E、右键环绕、第一人称转头、右键释放后仍按 W、滚轮、聚焦、捕获丢失和窗口失焦，共 13 项。实际输出从 175×223 / 最多 2 样本恢复到 700×894 并继续累计；几何更新、Morph / Skinning 重算及 GPU 回读均为 0。
