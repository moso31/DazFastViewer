# 要求与约束

- `src/render_ir` 不包含 DAZ、Cycles、Win32 或 JSON 类型；`src/daz` 不包含 Cycles 类型。
- IR 使用米、Z 向上、右手坐标系。实例变换为行存储 3×4 矩阵，作用于列向量。
- Mesh 保存位置、三角形、逐角 UV、材质槽。Instance 指向 Mesh 并绑定材质，不能通过展开所有实例掩盖共享关系。
- 相机视场角为弧度，沿较短画面边；相机局部 +Z 指向视线，+Y 向上。
- 首次载入时检查索引、材质槽数量、非有限值和相机尺寸；增量变更必须在修改 Cycles 前完成参数校验。
- 相机更新只写相机，不创建 Mesh、Texture 或 Shader。完整载入仅允许一次，之后通过 Delta 更新。
- 材质更新可替换已有材质的基础参数及已有贴图引用；本阶段不支持增删资源或替换贴图文件。
- 相机同步沿用 Scene 锁与实际渲染 epoch，禁止用最新 UI epoch 冒充已有帧。
- 验证窗口默认第二屏；找不到第二屏时失败，不自动转到主屏。
