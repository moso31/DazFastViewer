# 需求与边界

- 使用用户指定 Genesis 8.1 Basic Female 和 Food Plate with Fries 原始资产，保持内容库只读，不将商业模型或贴图提交到 Git。
- 独立加载器导出完整语义场景 JSON：网格、逐角 UV、材质槽、实例、材质参数、贴图、相机、灯光和环境。
- Blender 后台调用 DAZ Importer，使用未变形基础网格；不要求 DBZ，不应用 Morph、蒙皮或细分。
- 导出插件生成的材质节点、连接、默认参数、贴图路径和色彩空间；固定导入设置并记录版本。
- 对比前验证独立导入的基础几何，再统一三角形与 UV、相机、灯光、采样和色彩管理。共享几何的材质对照不冒充独立完整场景一致性验证。
- 失败须返回非零状态并保留日志，不能以缺贴图、回退 CPU 或空场景生成成功报告。
- 新材质参数必须经 DAZ → Render IR → Cycles Adapter，不将 DAZ 通道名放入 Adapter。
- 验证材质 Delta 修改图像且不重建网格；GPU 上传字节尚未计数时明确标注。
- 参考与 Runtime 不一致的材质、设置及未支持通道必须保留可审查报告。
