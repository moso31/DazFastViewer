# 设计

`--export-scene` 在创建设备之前完成 DSON 加载、预览取景和 Render IR JSON 导出。离线渲染也导出同一场景契约，确保参考工具使用的是实际被渲染的参数。

`tools/reference/blender_reference.py` 作为独立 Blender 后台脚本运行。使用 `--factory-startup`，仅在当前进程启用插件、调整公开设置，不保存用户偏好或启动文件。完整保留材质图记录，按实例检查基础顶点和材质槽；对照渲染显式使用契约的三角网格及逐角 UV。

相机采用米制 Z 向上坐标，把 Runtime 的局部 +Z 朝前转换为 Blender 的 -Z 朝前；视场角沿较短画面边。灯光采用同样的归一化面积光功率和尺寸。输出线性 EXR 与 Standard/sRGB PNG，关闭降噪和自适应采样，固定 seed 1337。

对照结果保存在被 Git 忽略的 `artifacts/material-reference` 中；规范目录只保存无商业资产的执行摘要。图像误差用于定位差异，不能单独证明完整材质兼容。Golden 状态必须由明确的图像与结构检查结果决定。

第一轮 Bump 映射支持显式高度范围和缺省近似，后者发出兼容性诊断；参考的几何 / UV / 纹理尺度估计尚未独立实现。折射粗糙度、皮肤散射及额外高光层继续保留差异。不得将参考节点图直接序列化成产品运行时依赖。
