# 最小要求

1. 原生 C++ 解析纯 JSON 和 gzip DUF / DSF，遵守数组 `count`，拒绝损坏内容。
2. 支持内容库根目录、UTF-8 百分号编码路径和文件内 / 外部 fragment，缓存已解析文档。
3. 多个内容库按显式输入顺序查找；可从输入文件祖先中推断包含 `data` 的内容库。依赖缺失时明确指出 URI 和来源。
4. 支持指定输入的三角形 / 四边形、材质组、UV Set 和逐多边形顶点 UV 覆盖。不得把 UV 接缝记录中的几何顶点编号当作局部角点编号。
5. DAZ 厘米、Y 向上转为 IR 米、Z 向上，采用 `(x,-z,y)/100`。常用静态 pivot SRT 支持 `current_value` 和节点继承。
6. 映射基础颜色、粗糙度、金属度、透明度、折射权重 / IOR、切线法线及当前支持的贴图；报告未映射通道。
7. 遇到未实现的 SubD、Modifier、Skinning 等语义，预览模式给出诊断；`--strict-dson` 拒绝带诊断的输入。
8. `--inspect` 不创建窗口、不枚举 GPU；输出依赖、网格统计、材质映射和兼容性报告。
9. 预览从创建时即位于第二屏，固定默认 1600×900；缺屏或窗口放不下应明确失败。

用户资产是只读测试输入，不复制到项目源码或改写原文件。
