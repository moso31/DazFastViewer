# 需求

- UI 全程使用 Unicode；菜单、标签、搜索、文件路径及数字编辑支持中文，第三方资产原有名称保留。
- 先选中场景对象，再修改其 Morph 或变换；多个实例参数互不污染。
- 发现 Genesis 8 / 8.1 兼容资产的 Morph，读取 min / max / default / label / group / visible / auto_follow。仅同一目标拓扑可接收稀疏顶点差值。
- Morph 为不可变基础顶点加权求和，恢复零值不得累计漂移；只遍历非零 Active Set。
- 相机、材质、对象变换、Morph 分别传播脏标记；相机移动不扫描或求值 Morph。
- UI 不持有 Cycles Scene 锁、不等待完整采样；编辑值覆盖合并后由渲染工作线程应用。
- 新建或修改顶点不能重建无关网格、材质与纹理；法线与 BVH 必须随几何更新。
- 用户资产只读、demo 只在第二屏，不重复性能回放。
- 不支持的 HD、Formula / ERC / JCM、Alias 和目标不匹配须明确诊断，不给用户提供看似成功的无效滑块。
- “项目 → 项目设置”持久保存多个内容库及优先级，启动和场景加载使用同一配置；同路径资源先匹配者优先，显式记录覆盖与缺失。
- 发现带 / 不带顶点差值的参数、子节点别名、递归目录及外部参数引用，保留来源、所属节点、分组与支持状态；不能把目录缺失、格式解析失败和暂不支持求值混为一类。
- G8 与 G8.1 分别核对，不能跨代强行恢复被空文件屏蔽的参数。兼容多段 gzip DSF，同时拒绝损坏成员与非法尾部。
