# 设计与取舍

## 通道

`JointChannel` 保存原生通道描述，`JointPose` 保持输入。加载器先读取基础 DSF，再合并当前 Figure 下的 DUF 骨骼实例覆盖。界面从描述生成控件；不存在的通道不凭空生成，隐藏参数由现有开关控制。

## 求解

采用带限位和回溯的阻尼最小二乘法，直接在已有骨骼旋转顺序、orientation、中心和缩放语义下求解。相比只支持三个节点的解析 Two-Bone 解，统一求解能保留 Genesis 8 的 Bend／Twist 拆分骨、指节链及各轴限制。共线内收目标有小角度奇点种子；固定点作为附加加权位置目标。此项是总体规范 Two-Bone IK 实现方式的调整，四肢交互目标保持不变。

求解使用起始时已求值的骨架，并把起始 ERC 与手动输入之间的旋转差保留到预览；提交时仅写回姿态改变量。预览中不重新求值姿态相关 JCM，因此不能把灰模预览当作最终皮肤或服装效果。

## 交互与性能

原生窗口保存鼠标按下序号、选择世代、起点和最新位置。移动合并为最新输入，不积压鼠标事件；按下、松开和取消语义独立保存。相机朝向决定拖动平面，深度取起始关节点；因此普通左键在屏幕平面移动目标，深度调整可先改变观察角度。

渲染线程只求解宿主骨架与预算内基础网格，并通过 OpenGL 显示灰模和骨骼链。暂时暂停 Cycles；不创建低细分场景、不修改资产、不重复处理复杂穿戴物。松手由 UI 根据文档世代和输入 revision 接收一次姿势，再由既有完整管线更新。最终恢复仍需要实际服装、发丝、碰撞和 GPU 同步时间，单独计时，不混同于拖动求解耗时。

## 边界

当前不新增 TriAx 轴权重、独立缩放权重实现、动画或 dForce。完整 DAZ Studio Golden 和任意姿势无穿插依旧单独验收。

## 2026-09-25：角度固定与恢复提速

“固定位置（IK）”和“固定角度（IK）”独立保存、默认关闭。角度取开启时部位的世界旋转，剥离实例和骨骼缩放；用最短旋转向量构建约束，同时限制三个方向，包括 Twist。只固定角度仍允许拖动末端位置，固定位置和角度可以同时开启。取消／恢复姿势／场景身份规则沿用原位置固定。

带固定约束的 IK 松手时先重新求公式与骨架，按完整 ERC 的结果校准输入，再执行一次完整几何更新；校准不载入 Morph 差值，不做蒙皮、服装、碰撞或 Cycles 同步。这样避免预览中冻结的 ERC 偏移在提交后改变固定朝向。校准保留约束误差最小的输入，并报告不可达角度。

整体变换快路径依赖相对形状不变。IK 改变局部几何，仍需重新碰撞；优化互不依赖的顶点及反向最近面查询，并在同次求值内缓存重复查询。依赖顶点写回的面修正保持原顺序，缓存仅在查询点与只读碰撞表面完全相同时命中。保留串行参考路径用于逐顶点对照，不减少碰撞次数或采样点。

面内采样点先并行查询，再按原来的面顺序修正；若前面的修正移动了当前采样点，就以新坐标重新查询。IK 松手后已有灰模保留画面，因此直接恢复完整分辨率，不再插入旧几何低分辨率预览和新几何低分辨率预览。
