# 验收要求

1. 骨骼原生平移、旋转、缩放和总缩放按真实资产通道显示。可编辑通道实际改变对应实例；锁定、隐藏和不支持的权重模式有明确处理。
2. FK 使用局部骨骼输入；不得套用角色整体变换。手指、手脚、头部、眼球和具有姿态通道的附件分别验收，不能仅验证 Bend／Twist 两种名称。
3. 左键按下时必须已经只有一个选中项，且属于射线命中的角色。单选该角色的一个骨骼也属于单角色操作；同角色多骨骼、多角色、灯光／道具混选均拒绝 IK。Ctrl／Shift／Alt 组合不启动 IK。
4. 首次点击未选中的角色继续完成选择，不在同一次按下中启动 IK。普通单击保留部位选择；超过系统拖动阈值后才改变姿态。
5. 四肢、手指和局部骨骼链根据层级求解。遵守原生锁定和角度范围，不拉长骨骼，不移动无关分支。不可达目标使用最接近的可行姿态。
6. 支持部位位置固定及角度固定，两个开关独立且默认关闭；在 IK 或骨盆骨骼 FK 编辑时通过对应骨骼链维持世界位置／朝向。只固定角度仍可移动位置，不可达约束明确提示。固定状态属于当前编辑会话，场景身份变化时清除。
7. 交互预览最多 40,000 个基础三角形；不执行发丝、服装碰撞、细分、完整 Morph 或 Cycles 几何更新。预览以基础体型为准，姿态 JCM 在松手后更新。
8. 松手后保留最后输入并恢复完整求值；不改变用户细分、显隐、材质与采样设置。Esc、失焦、场景／选择改变取消拖动，旧结果不能写入新场景。
9. 验证恢复无漂移、多角色隔离、现有点击选择和相机导航。全部 GUI 验证仅在副屏。
