# 008：骨骼属性编辑与左键 IK

用户已授权实现本阶段。选中角色部位后应能通过资产原生参数摆姿势；只有按下鼠标前已经单选该角色时，左键拖动才启动 IK。

FK 以 DSF 骨架定义叠加 DUF 实例覆盖为准，保留名称、分组、显示状态、百分比、步长、锁定和限位。Bend、Twist 仅是部分通道的显示名称，不是所有部位的固定参数列表。原有 Morph／ERC 控制器继续显示。

IK 拖动使用有预算上限的宿主基础网格预览。拖动不求值全场景服装、StrandBasedHair、碰撞、细分和 Cycles；松手提交一次完整姿势，复用现有 ERC／JCM／蒙皮／穿戴物管线。资产的细分与显隐设置不被修改。

按用户本轮直接实施指令沿用当前模型执行，不重复模型确认。FABRIK 和 PowerPose 不作为本阶段前置依赖。
