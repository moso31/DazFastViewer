## 支持范围与人工反馈

支持 Genesis 8／8.1 Female、Male 的 Body、Hands、Head。Body 36 个、Hands 44 个、Head 5 个姿态点，总计 85 点；另有 6 个导航入口，其中 Face 入口禁用，模板下拉列表也没有 Face。男性使用对应的男性底图及点位，保留相同功能范围；G8／G8.1 男性支持点坐标已逐项比对一致。

人工记录中 85 项“一致”、6 项“有差异”已全部落实：

| 编号 | 最终行为 |
|---|---|
| B07 | 双肩联动组使用实心点加虚线外圈；固定状态另用小锁表示。 |
| B08／B09 | 左键纵向写入上臂 Bend（Z）；右键纵向转交对应 ShldrTwist 骨的 X Twist。保留左右侧符号。 |
| B26／B27／B28 | 每个成员读取 DSF 与 DUF 实例覆盖后的范围、锁定和限位。大腿与小腿分别计算变化，不共用角速度。 |

其他映射保留人工确认的官方差异：Body／Hands 左手腕右键纵向符号不同，整手／单拇指组使用不同符号和 size；单眼没有右键动作，双眼组右键只有水平反向联动。Pelvis 的原始 Bend／Twist／Side-Side 在生成配置时固定为已核对的原生轴，不依赖界面显示名称。

## 交互与姿势事务

右侧新增可停靠的 PowerPose 页，与对象属性面板共用停靠区域；可从“视图 → PowerPose”重新显示。Template Set 随角色自动匹配，Body／Hands／Head 可以通过下拉框或图中三角入口切换。底图从用户已配置的内容库读取，没有把 DAZ 图片、插件或解密密钥打包进程序；缺图时控制点仍可用并显示提示。

单击选部位或联动组；超过 3 个逻辑像素后拖动，横纵轴可以同时生效。右键轻点显示“定位到参数”“恢复加载时的本点参数”，支持 IK 链的单节点另有独立的位置／角度固定。右键拖动结束不弹菜单。Shift 在按下时固定为 0.1 倍精调，第二个鼠标键不改变第一键模式，滚轮不改姿势。

拖动值相对按下时的输入计算：`起点值 + 逻辑像素位移 × sign × 当前通道量程 / size`。重复同一位移不会累积；锁定轴不写入，限位由实际角色通道决定。本点恢复只恢复绑定通道的加载值，其他参数保持不变，包括加载时已有的越限姿势。

没有绑定的按键／方向、已到限位且继续向外拖动、最后回到按下位置的手势不会产生空提交。复杂场景的自动测试会先检查加载时的姿势，遇到已经到限位的测试方向时反向拖动，并在结果中记录实际位移。

绑定使用 Figure 实例、骨骼 ID、内部名称和原生别名。拆分工具轴显式转交 ShldrTwist、ThighTwist、Wrist，随后检查实际目标通道是否可编辑。相同角色的骨骼多选可表示联动组；跨角色选择、附件和不支持的骨架禁用面板编辑。菜单也验证打开时的实例与版本，防止旧菜单作用于新角色。

UI 只发送带实例、场景版本、输入版本与手势序号的最新鼠标状态。渲染线程使用按下前输入及有效姿势生成最多 40,000 三角形的宿主灰模；复用 008 的代理构建与呈现路径。拖动不进行完整 ERC／JCM、穿戴、发丝、碰撞、细分和 Cycles 几何更新，松手一次性进入已有完整更新流程。Esc、失焦、切页、改变选择、场景或输入版本变化取消手势，预览不污染正式输入。

整体平移／旋转写入现有实例变换，髋部平移写入 hip 骨的原生位移，二者保持独立。灰模与正式路径共用 `parameter_transform`，沿用角色自身轴心、加载时旋转、原生旋转顺序和位移坐标系；已平移的角色整体旋转不会绕世界原点转动。普通 FK 不自动补偿固定点；髋部拖动使用 008 的位置与朝向约束，提交时通过完整 ERC 重新校准。直腿压缩若卡在反屈限位，额外尝试合法的正向屈膝分支，只接受约束误差更小的结果。误差统计现取所有固定点的最大残差；不可达时仍保留限位并提示残差。

## 数据来源与重建

- `tools/powerpose/decode_templates.py`：从本机已验证版本的 DAZ 插件读取所需数据，独立解码 DXE；不加载或执行插件。详见 [DXE 研究](dxe-research.md)。
- `tools/powerpose/build_review.py`：产生原始审阅映射及核对页。

- `src/editor/powerpose_panel.*`：绘图、等比坐标命中与鼠标手势。
- `src/editor/powerpose_drag.*`、`renderer.cpp`：灰模预览、约束求解、版本校验和完整提交。

### 复杂场景发现并修复的恢复问题

带真实服装、GeoGraft 和发丝的场景中，上臂 Twist 恢复后出现约 27.45 毫米的残留几何差异。独立小场景确认：碰撞发生在最终接缝焊接之前，当某个插件没有重新蒙皮时，碰撞会使用上一次姿势的焊接边界，结果依赖编辑历史。

现于碰撞前更新当前 GeoGraft 接缝，并保留刚性跟随／插件碰撞后的最终接缝对齐。没有减少碰撞迭代或采样。新增 `ConformRuntimeTest::graft_collision_restore` 验证抬高宿主再恢复后服装逐顶点回到原位；测试在原顺序下失败，修复后通过。修改位于 `src/runtime/deformation.cpp`，属于 PowerPose 完整更新和恢复路径所需修复。

早期测试目录用于保留诊断过程，不计作最终通过证据：`gui-g8f` 缺少测试用几何探针，`gui-g8f-v2` 暴露直腿约束分支问题，`gui-hair-final` 向已经到达的限位外拖动，`gui-hair-v2`／`gui-hair-v3` 暴露上述接缝恢复问题。`gui-hair-v4` 在修复后通过全部 15 项且逐顶点恢复误差为零；最终发布版的验收目录见下表。

## 边界

支持的是上述确认过的三页映射，不是任意 DXE 模板加载器。Head 的额外表情点及 Face 未实现。人工记录没有提供逐像素定量测量，因此不能把本轮结果称为与 DAZ 速度逐像素相等；实现采用已披露的量程公式与原 size。灰模预览不求完整 ERC／JCM 和附件变形，最终画面在松手后求值。固定目标不可达时保留限位与残差，不保证任意姿态完全可达或无穿插。
