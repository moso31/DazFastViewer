## 原始问题表为什么不能直接等同于可恢复数量

原表记录的是每个参数当时首先遇到的阻碍。修复这个阻碍后，仍可能遇到 HD、无输出等下一层问题。

| 原始分类 | 原数量 | 已恢复可编辑 | 仍受阻及原因 |
|---|---:|---:|---|
| 顶点数不匹配 | 379 | 302 | 14 个实际不匹配、41 个无有效输出、22 个 HD |
| 公式引用或别名目标未解析 | 300 | 134 | 160 个公式 / 属性引用问题、6 个别名目标问题 |
| 控制器没有有效输出 | 54 | 39 | 6 个仍无输出、9 个下游仍受阻 |
| 骨骼属性别名、节点到网格绑定 | 17 | 1 | 16 个骨骼属性别名的交互尚未实现 |
| 原有 HD 数据 | 288 | 0 | 需完整 HD / SubD 实现 |
| 资产明确锁定 | 193 | 0 | 保留锁定语义 |

其中原 365 个 `-1` 计数项均通过新的身份 / 差值校验流程，最终分为 302 个可编辑、41 个无输出、22 个 HD。因此此前新增 354 不是完整修复上限，但也不能把这 365 项全部承诺为可编辑。当前相对原表前四类累计恢复 476 / 750 项。

当前 G8 共 755 个禁用条目：HD 310、锁定 193、公式 / 属性引用 160、别名目标 6、无输出 47、下游受阻 9、骨骼别名 16、实际顶点数不匹配 14。HD 从 288 增至 310 是阻碍分类变化，没有原本可编辑的参数退化。

## 仍有进一步修复空间

所有仍禁用的条目及独立取样无明显形变的新增条目，已按名称、节点、分组和源文件整理为[完整清单](remaining-morphs.md)，另提供可用 Excel 筛选的 CSV。读取失败资源单独列在附录。

1. **16 个骨骼属性别名**：Twist、Bend、Front-Back 等已解析到关节属性，但参数面板尚未提供到姿势输入的双向编辑。应结合 008 的 FK / IK 完成，并验证与姿势 DUF、JCM、重置的同步。
2. **错误目录 / 内部 ID 与真实缺失分开处理**：例如 Liya 引用了产品目录下的官方 Body 参数，完整声明地址又不匹配；同 ID 候选只能作为诊断线索。可增加可审查的项目级路径映射，确认包版本后再绑定。另有官方表情、Dayton / Brynn 等依赖在当前目录中没有找到候选，需针对缺失清单补充资源，而非重新解压全部内容库。
3. **无输出控制器的跨对象依赖**：例如 BGM Heavy Clothing Smoother、Children Clothing Helper、部分 Eyelashes 项，原文件确实是零差值、零公式，部分带 `auto_follow`。是否对服装 / 睫毛有效，需要加载对应资产并追踪跨对象关系；应放入 FitTo / AutoFollow 阶段验证。不可凭名称假定它能改变裸角色。
4. **HD / SubD**：独立能力建设，不通过忽略 HD 数据来宣称完整支持。14 个真实顶点数不匹配项也继续拒绝套用。

物理路径仍优先。存在的空覆盖、G8.1 代际覆盖、多个文件声明同一 URI / ID、未经验证的网格目标继续拒绝；不按全局显示名称猜测，不改写用户资源。G8.1 旧 Eyes Closed / 眼睛方向空覆盖保留，新版 Eye Blink 正常。

## 验证与边界

- Release 编译及 8 项轻量 CTest 通过，新增检查覆盖 `-1`、索引边界、绑定身份、搬迁地址、别名、根目录优先级、空覆盖、歧义与跨角色拒绝。
- G8 / G8.1 各载入一次，检查重点参数、原有 Morph / Alias / JCM 和各 40 个姿势。476 / 614 个新增条目均通过取样求值和恢复，无拒绝样本；原可编辑集合无损失。
- 新增条目中，G8 有 71 项、G8.1 有 63 项在独立取 0.5 / 1（受自身范围限制）时位移不足 `1e-6 m`，单独列为无明显位移。它们可能依赖姿势、开关或组合输入，**不把这些条目的通过视为视觉效果已验收**。
- 30 组原始 DSF 差值与独立 mathutils / NumPy 蒙皮对照通过，最大顶点差 `6.193751e-7 m`。覆盖三项重点体型与姿势组合、Yuki / Mariko / EasyFeet 等样例。
- 数学参考初次发现脚本只计算当前滑块，漏计 Yuki 的 Body / Head / Youth 以及 G8.1 默认开启的 `CTRL Vo Xiao Mei`。补齐原始公式贡献后通过，并人为扰动骨骼中心确认检查能报错。原始失败记录保留。这里部分输入采用 Runtime 的有效 Morph 权重，**不等于整张 ERC 图独立验证或 DAZ Studio Golden**。
- 一次副屏流程检查上述六个滑块、恢复及相机操作，全部通过；显示器 `VG279QL1A`，窗口 `(2729,55,1580,920)`。未重跑性能基准。

资源初值继续遵循文件：修复后原来因兼容性禁用、且默认非零的控制器会参与初始形态。G8.1 当前资源中的 `CTRL Vo Xiao Mei` 初值为 1，可能影响基础角色加载后的外观；这不是用户滑块操作的累积漂移。

最终原始证据：`artifacts/spec007-compatibility/final`。第一批 `validated` 仅为中间记录。可提交摘要见 [compatibility-summary.json](evidence/compatibility-summary.json)，不包含商业顶点差值。
