# 007 参数兼容性修复

用户授权：先中文提交已有实现，再修复一版。原 007 已提交为 `da5d4f8`（完成 Spec 007：实现 ERC 与 JCM 并复测 Morph 参数）。本批优先 Ren Yao、BGM Ava、BGM Big Girl Base，并批量检查相同规则恢复的其他参数。

## 修复范围

- 顶点总数保留有符号整数。对实际资源使用的 `-1`，依赖所属资产 / 网格身份及逐条差值校验；不把其他负数或明确错误的正数计数当作未知。
- 支持通过基础 DSF 的 SkinBinding 确认 Figure 节点与唯一几何的关联；无明确关联、多几何歧义和跨角色引用继续拒绝。G8.1 仍需原有拓扑兼容验证。
- 精确文件路径缺失时，完整扫描后在引用所指定的目录中按内部 ID 查找唯一参数，遵循内容库优先级。恢复同时用于公式和 Alias，并记录原 URI、实际文件及原因。
- 第二批增加 `asset_info.id` 索引：精确磁盘路径不存在时，优先查找声明资产 URI 与内部 ID 同时匹配的唯一条目，再使用上述同目录恢复。只索引当前角色已经接受的参数，不按全局同名参数猜测；多个文件声明相同地址和 ID 时拒绝恢复。典型对象为 EasyFeet、Yuki 和 Mariko。
- 保留存在但为空的文件、代际覆盖和同目录歧义；不使用全局显示名称匹配。BGM Belly Smooth 在不同作者目录中有不同数据，不能混用。
- 控制器没有有效输出时，尽可能指出被禁用的下游参数及其原因。

不改写用户资源文件、不要求手动解压。HD / SubD、骨骼属性 Alias 的交互支持和真实缺失依赖不在本批承诺范围。

## 验证安排

新增合成检查覆盖计数、绑定身份、目录恢复、声明地址搬迁、URI 编码、别名、优先级、空覆盖、歧义、跨角色拒绝、索引越界与实际变形。真实角色一次载入后运行指定参数、原有参数 / 姿势回归，以及对照上版目录的新增可编辑参数半值 / 满值 / 恢复检查；没有可见变化的条件型控制器单独统计。

以旧版 `artifacts/spec007/validated/{g8,g81}/morph-catalog.json` 为比较基线，第一批中间证据位于 `artifacts/spec007-compatibility/validated`，最终证据写入 `artifacts/spec007-compatibility/final`。三项重点参数增加姿势组合及独立数值参考，第二批选取三个代表参数纳入实际变形检查；最终在第二屏做一次滑块验证，不重跑性能基准。结果完成后另写执行报告，保留失败证据。
