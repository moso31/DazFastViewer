## 实际交付

新增独立 C++ Formula / Property Graph，按角色绑定资源 URI 与 Alias，支持 RPN、sum / mult、布尔开关、线性 / 常量 / TCB 样条、循环隔离与依赖脏传播。Formula → Morph / JCM → Skinning 使用统一管线；手动输入与最终求值分开，Qt 参数面板显示最终值。相机操作不进入变形求值。

## 验证结果

- 七项工程 CTest 全部通过，包含公式阶段 / 运算 / 样条、循环隔离、脏传播、两个角色的独立公式状态、节点缩放传递、非法编辑回滚，以及此前 Morph / 姿势测试。
- G8 / G8.1 各 40 个 Bed Hogs II 姿势通过。每个姿势触发 51～72 个 JCM，恢复顶点误差均为 0。G8 的眼睛上下 / 左右控制器全部应用；G8.1 仅这两个旧控制器仍按本代空覆盖报告未应用，各涉及 33 个文件。
- `lShin.rotation/x = -5.5` 时 Flex Quad Left 自动值为 `0.5`；关闭 Base Flexions 后为 0。已修复 bool 默认 true 被当成 0 的问题。Base Joint Correctives 的默认开启值同样保留。
- Blender 5.2.2 后台 mathutils / NumPy 独立检查 12 组数据：直接参数、表情、JCM，以及 Arms Length 与姿势组合。独立重读 DSF 差值 / 权重并计算两阶段 DQS，最大顶点差 `4.631754e-7 m`，低于 `2e-5 m` 阈值。Arms Length、Chest Scale、HS Sanny Shy 和节点缩放另有独立标量公式检查；眼睛复杂控制链的顶点对照使用 Runtime 求值后的通道，不宣称是完整独立 ERC Golden。
- 最终 Qt 副屏流程操作五个真实滑块、逐个恢复并移动相机，通过。窗口位于 `(2729,55)`、显示器 `VG279QL1A`；只创建角色与地面 2 个网格，10 次顶点更新，最终最大位移 0，相机阶段没有新增 Formula / Morph / Skinning 求值。截图确认中文、可编辑状态及最终值显示正常。

开发过程中保留了失败和中间证据：第一次 G8.1 检查错误地要求旧眼睛方向控制器生效，已按资源空覆盖修正断言；最终再加入基础节点公式，修正了 Arms Length 的缩放传递。首次截图捕获早于 Qt 文本重绘，测试入口补充等待一次绘制后再捕获。最终证据统一位于 `artifacts/spec007/validated`，早期 `g8` / `g81` / `g81-final` / `editor` 目录不代表最终版本。没有重跑性能基准。
